# Tom's Phonics Universe — 星际航行与成长系统设计方案

> 版本：V1.0 ｜ 日期：2026-10-26 ｜ 状态：产品设计草案  
> 适用设备：iPad 横屏优先，兼容桌面浏览器  
> 视觉方向：Minecraft 启发的原创 2D 方块宇宙（不直接使用第三方受版权保护素材）

## 当前实施状态

首次开发按用户确认范围收敛为地球—虚构补给空间站，两地点已实现。前三课每课共 90 燃料（30/20/30/10，无独立复习奖励），旧有效记录补发；首次抵达扣 50，往返免费。空间站提供三轮交流和补给先锋收藏卡，支持保存恢复。

具体交付与后续拆分见 [开发方案](SPACE_EXPLORATION_DEVELOPMENT_PLAN.md)。以下 62 个节点已全部加入六星域概览，支持查看类型、备注与开放状态；额外保留虚构补给站，共 63 个地点。除地球和游戏补给站外，节点航行与互动尚未实现。完整科技树、科普图鉴、月球/火星互动和导入导出仍属于后续目标。原始示例经济参数不作为当前代码的奖励配置。

## 1. 项目背景与目标

Tom's Phonics Universe 是父亲陪伴一年级孩子学习英语的亲子教育游戏网站。以**系统自然拼读 + 口语情景对话**为教学主线，以方块宇宙冒险增加好奇心和持续学习动力。本文件新增可持续成长的**星际航行系统（Space Exploration System）**：

**完成课程与复习 → 获得探索燃料 → 乘飞船抵达真实天体或科研区域 → 触发科普、英语互动及建造奖励 → 升级飞船 → 飞向更远宇宙。**

设计目标：
- 把“学了多少英语”转化为可见的“探索了多远”，让每一次学习都有积极反馈。
- 从地球出发逐渐认识太阳系、邻近恒星、银河系乃至银河系外的天体。
- 将天文知识、英语实践与 Minecraft 风格方块建造相结合。
- 支持父亲陪同游戏：口语表现由父亲确认，第一版不需要录音、语音识别、AI 后端。
- 强调长期兴趣与自主性，不通过罚燃料、倒计时或刷题焦虑驱动学习。

## 2. 核心体验与主循环

```text
进入网站 → 查看当前位置和下一目的地
       ↓
自然拼读 / 单词拼读 / NPC 情景对话 / 复习
       ↓
获得燃料、方块材料与探索记录
       ↓
选择可达目的地 → 航行过场动画 → 抵达节点
       ↓
触发星球特色互动、英语任务、宇宙知识卡
       ↓
点亮图鉴 / 建造基地 / 收集引擎升级资源
       ↓
解锁下一批目的地（旧节点可免费回访）
```

两套资源：

| 资源 | 主要用途 | 获取方式 | 原则 |
|---|---|---|---|
| **探索燃料** | 前往**新**目的地 | 学课、拼读、对话、复习 | 可以消耗；不因错误扣除；旧节点免费回访 |
| **建造方块** | 飞船外观、基地、特殊装饰 | 到达节点、剧情、里程碑 | 即时奖励；与英语练习形成关联，但不锁住基础学习 |

另设**引擎科技等级**（不是可消耗货币），通过课程里程碑与探索任务解锁新星域，避免远距离航行只变成囤燃料。

## 3. 统一视觉与操作

- 主要布局：iPad 横屏，一屏展示星图、飞船、当前燃料、下一航点与任务按钮。
- 风格：原创像素/体素风的二维分层地图、方块按钮、卡通飞船、清晰的标准字形；文字不要采用难辨认的像素体。
- 输入：大尺寸触屏按钮、点击为主，拖动为辅；统一兼容 mouse/pointer/touch，不依赖 hover。
- 动效：发射、推进、星球接近、轨道抵达、图鉴点亮；轻量 CSS/Sprite 优先，不上 3D 引擎。
- 音效：短促的点按、燃料增加、发射与抵达反馈；提供静音控制。
- 无需登录的首版可用 localStorage 保存进度；重要奖励防重复领取。

## 4. 航行与燃料机制

### 4.1 初始奖励规则（待儿童实测调整）

| 行为 | 探索燃料 |
|---|---:|
| 完成新课教学 | +30 |
| 完成拼读游戏 | +20 |
| 完成情景对话 | +30 |
| 复习旧单词与规则 | +10 |
| 完成整节课程总结 | +10 |
| **整节课示例合计** | **100** |

规则：
1. 奖励与“认真完成、主动尝试、复习掌握”关联，不惩罚做错题；口语由父亲确认。
2. 同一课程的同一奖励按唯一事件 ID 防重复领取；重刷页面不能刷燃料。
3. 新节点消耗燃料；**已发现节点之间回访免费**，防止复习与探索受到限制。
4. 保持“短、中、长”三级节奏：小节点约 0.5–1 节课、普通星球约 1–2 节课、大型里程碑约 3–4 节课。
5. 关键星域由引擎等级解锁，防止到远处的体验变成无止境攒数值。
6. 若孩子长时间未达到某航点，提供支线小节点、趣味复习和阶段探索奖励；不设置连续登录惩罚。

## 7. 飞船科技树与升级

| 引擎 | 对应星域 | 设计含义 | 真实性 |
|---|---|---|---|
| MK I：化学火箭 | 地月/内太阳系 | 初期小火箭 | 真实推进原理 |
| MK II：离子推进 | 巨行星/边疆 | 深空探测 | 真实推进原理；具体旅程游戏化 |
| MK III：聚变飞船 | 邻近恒星 | 星际推进升级 | 概念性方案，非成熟实用载人技术 |
| MK IV：曲速飞船 | 银河深空 | 扩展远距离星际剧情 | 科幻技术 |

除了引擎技术，外观可升级：驾驶舱、太阳能板、雷达、机械臂、着陆腿、护盾装饰、颜色/旗帜、宠物机器人。外观升级尽量让孩子直接看出区别。升级主要由课程阶段、剧情和探索成就解锁，而不是昂贵的重复付费型资源循环。

## 8. 到达节点后的内容模板

**每个重要节点至少提供“一件有趣的事”**，避免抵达后仅显示一句恭喜。

通用节点内容：
- 抵达动画与天体展示；
- 1 张真实天文知识卡（图片/比例/趣味问题，标明科学事实与科幻设定）；
- 1 个英语互动：NPC 对话、指令寻物、拼读方块合成或阅读线索；
- 1 项探索奖励与图鉴条目；
- 回访入口与复习支线。

特色任务举例：

| 节点 | 趣味事件 | 英语目标 | 奖励 |
|---|---|---|---|
| 月球 | 第一次低重力登陆 | Go / Stop / Jump | 月球旗帜 |
| 火星 | 用方块搭建第一座基地 | I need a block. | 火星基地组件 |
| 木星 | 识别大红斑与巨行星 | big / small, I can see... | 风暴徽章 |
| 木卫二 | 探索冰壳与地下海洋假说 | ice / water / under | 冰晶材料 |
| 土星 | 在行星环附近收集冰晶 | Find the blue crystal. | 环形装饰 |
| 冥王星 | 辨认矮行星及其卫星 | far / cold | 远行徽章 |
| 比邻星 | 初识光年与最近恒星 | near / far | 星际导航器 |

### 科普可信度

- “真实宇宙知识”与“游戏想象”在 UI 中明显区分。
- 星系、恒星、行星、卫星、矮行星、黑洞等分类正确。
- 宇宙尺度采用“非按真实比例”说明；必要时给真实距离、单位和科普解释。
- 动态位置、天体发现数量和分类等可变信息以后定期核验。

## 9. 星际收藏图鉴

每发现一个节点点亮专属卡片，展示：
- 名称（中文/英文）、天体类别、星域。
- 真实天文图片或可靠的科普插画。
- 一条适合儿童的有趣事实和一个小问题。
- 首次抵达日期、完成的任务、获得的收藏品。
- “再去看看”按钮：**已到达节点免费回访**。

可设置可选收藏目标，例如“认识四大类天体”“收集所有巨行星的图鉴”，但不因漏一天学习取消奖励。

## 10. 与课程、对话系统的整合

现有三个文档的分工：
- `docs/PRD.md`：产品定位、页面布局、核心交互。
- `docs/CURRICULUM.md`：48 周、六大拼读星球的课程规划。
- `docs/DIALOGUE_DESIGN.md`：NPC 情景、对话分支、父亲确认。
- **本文件** `docs/SPACE_EXPLORATION.md`：燃料、星域、航线、升级、图鉴。

注意两个“星球”概念：
1. **教学星球**：48 周课程的六个学习阶段。
2. **探索目的地**：真实宇宙中的天体/区域和少量虚构设施。

它们是两个维度：完成教学阶段能解锁新引擎和星域，但每个课程可以获得燃料，自主选择已开放的探索目的地。建议使用 `curriculumStageId` 和 `regionId/nodeId` 分别管理，避免业务模型混乱。

### 11.1 关键状态与持久化规则

- `locked`：未开放，仍可查看模糊预览。
- `available`：满足前置条件，可检查燃料并起飞。
- `traveling`：播放航行过程动画。
- `discovered`：已到达，点亮图鉴、可免费回访。
- `completed`：完成该地点核心剧情任务。
- 起飞操作需**原子化地扣燃料与解锁目的地**，防止重复点击造成错误；首版前端可通过状态更新和幂等 ID 简化实现。
- 刷新后保留燃料、航点、发现节点和奖励明细；如暂用本地存储，提供导出/导入存档入口以降低丢失风险。

## 13. MVP 验收标准

1. 孩子可在 iPad 浏览器横屏打开星际地图，明确看到当前位置、下一站和燃料余额。
2. 完成英语任务后，燃料变化正确；同一奖励无法通过刷新无限领取。
3. 燃料不足、引擎等级不足时，按钮与提示准确；满足条件则能起飞抵达。
4. 每次抵达后发生明显变化：地图标记、动画、知识卡或物品奖励。
5. 旧节点可免费回访，至少一处旧节点能够触发英语复习任务。
6. 父亲能在没有录音识别的情况下陪伴孩子完成口语任务。
7. 整个系统不会因答错、离线几天或未连胜而惩罚孩子。
8. 教学与游戏界面可区分科学事实与虚构设定。

## 14. 风险及设计原则

- **重复刷题**：不要以高额燃料迫使孩子机械重复；应有多样化课程、小游戏和即时目标。
- **注意力偏移**：每次航行或升级应与学习成果直接相关，避免孩子只想看动画。
- **后期经济失衡**：以完成一课可获得约 100 燃料为初始基准，长期目标必须配平并通过引擎升级分层。
- **地图混乱**：一次只展示当前星域及相邻可预览节点；提供“全宇宙概览”而非铺满 60 个图标。
- **天文误解**：地图是游戏路线图，不是实际比例图；非真实设施和科幻推进系统要明显标注。
- **家庭使用优先**：让父亲成为共同探险伙伴，而非增加大量审题和管理负担。

## 15. 结论

该系统最有价值的设计不是燃料本身，而是提供持续可见、不断扩大的探索目标：**今天学会一个新声音，明天能抵达一个新世界。**

推荐开发顺序：**星图 → 燃料获取 → 飞船抵达 → 图鉴/科普 → 月球和火星互动 → 飞船升级**。先做真实可玩的垂直切片，再逐步扩展 60+ 内容节点，而不是一开始开发完整宇宙。
