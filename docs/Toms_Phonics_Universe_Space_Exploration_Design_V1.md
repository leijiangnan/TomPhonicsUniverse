首轮曾收敛为地球—虚构补给站。2026-11-11 按用户最新要求，地月空间全部 9 航点已接入航行、首次扣费、免费回访和对应起终点 3D 场景；费用依次为 0/50/50/100/40/40/60/60/100，共 500。当前第 1–16 课每课仍最多 90 燃料（30/20/30/10，无独立复习奖励），旧补给站 -50 事件不重算。补给站三轮交流和收藏卡保留，电脑后台统一保存学习及航行记录。

具体交付与后续拆分见 [开发方案](SPACE_EXPLORATION_DEVELOPMENT_PLAN.md)。以下 62 个节点已全部加入六星域概览，支持查看类型、备注与开放状态；额外保留虚构补给站，共 63 个地点。地月空间 9 点可航行，其余五个星域尚未开放航行；月球指令游戏和其他新节点英语任务未实现。2026-11-04 已优化首屏航行控制台，增加轻复习入口和经校验、摘要确认的存档导入导出。完整科技树、独立科普图鉴与月球/火星互动仍属于后续目标。原始示例经济参数不作为当前代码的奖励配置。

2026-11-05 的视觉与声音跟进已实现三层星云、可关闭的轻动效、明确的「声音与音乐」面板及主动播放的原创轻音乐。学习页面保持安静；视觉与音频分别按任务、用户选择和设备状态控制，规则见第 3 节及 [PRD 的背景取舍](PRD.md#44-背景可见性与专注的取舍)。本文中未标注已实现的科技树、建造、完整图鉴和航线扩展仍为规划，不能作为开放入口。

## 1. 项目背景与目标

Tom's Phonics Universe 是父亲陪伴一年级孩子学习英语的亲子教育游戏网站。以**系统自然拼读 + 口语情景对话**为教学主线，以方块宇宙冒险增加好奇心和持续学习动力。本文件新增可持续成长的**星际航行系统（Space Exploration System）**：

长期体验愿景如下，其中独立复习奖励、建造和升级尚未实现：

**完成课程与复习 → 获得探索燃料 → 乘飞船抵达真实天体或科研区域 → 触发科普、英语互动及建造奖励 → 升级飞船 → 飞向更远宇宙。**

设计目标：
- 把“学了多少英语”转化为可见的“探索了多远”，让每一次学习都有积极反馈。
- 从地球出发逐渐认识太阳系、邻近恒星、银河系乃至银河系外的天体。
- 将天文知识、英语实践与 Minecraft 风格方块建造相结合。
- 支持家长陪同游戏：口语表现由家长确认，录音不是完成条件。已实现课程可选本轮临时录音回放；语音识别、自动评分与 AI 后端未实现。
- 强调长期兴趣与自主性，不通过罚燃料、倒计时或刷题焦虑驱动学习。

## 2. 核心体验与主循环

下图包含长期愿景。当前实际循环为「完成课程阶段 → 记录固定燃料事件 → 地月空间 9 航点探索与免费回访 → 科普详情及既有补给交流与收藏」；轻复习、重玩、录音、点读和地图装饰均不单独发燃料。建造方块、引擎升级与完整图鉴尚未接入。

```text
进入网站 → 查看当前位置和下一目的地
       ↓
自然拼读 / 单词拼读 / NPC 情景对话 / 复习
       ↓
获得燃料、方块材料与探索记录
       ↓
选择可达目的地 → 航行过场动画 → 抵达节点
       ↓
触发星球特色互动、英语任务、宇宙知识卡
       ↓
点亮图鉴 / 建造基地 / 收集引擎升级资源
       ↓
解锁下一批目的地（旧节点可免费回访）
```

两套资源：

| 资源 | 主要用途 | 获取方式 | 原则 |
|---|---|---|---|
| **探索燃料** | 前往**新**目的地 | 当前来自课程三个阶段与整课完成；独立复习奖励为后续设计 | 可以消耗；不因错误扣除；旧节点免费回访 |
| **建造方块（规划）** | 飞船外观、基地、特殊装饰 | 拟来自到达节点、剧情、里程碑 | 不锁住基础学习；当前商店物品和补给卡不兑换燃料 |

后续拟设**引擎科技等级**（不是可消耗货币），通过课程里程碑与探索任务解锁新星域；当前没有该等级或解锁规则。

## 3. 统一视觉与操作

- 主要布局：iPad 横屏，首屏突出飞船、当前位置、当前燃料和一个可执行任务；完整星域概览在控制台下方持续可见，窄屏允许正常滚动。
- 风格：原创像素/体素风的二维分层地图、方块按钮、卡通飞船、清晰的标准字形；文字不要采用难辨认的像素体。
- 输入：大尺寸触屏按钮、点击为主，拖动为辅；统一兼容 mouse/pointer/touch，不依赖 hover。
- 动效：当前使用 CSS 星光、星云、路线流动、飞船悬浮及短抵达反馈；原创 SVG 承担星球和飞船插图，不引入整屏循环 GIF 或 3D 引擎。更多推进和完整图鉴演出仍属规划。
- 声音：顶部「声音与音乐」面板提供可见状态和明确的播放/暂停操作；当前已实现点读与可选轻音乐，燃料增加、发射等独立提示音不视为已实现。
- 无需登录的首版可用 localStorage 保存进度；重要奖励防重复领取。

### 3.2 背景、声音与学习任务的分工（已实现）

背景使用蓝青、紫色云团及下方云带三层渐变。最初的低透明度星云大多落在视口外，用户只能看到少量白点，因此将云团移入画面并增强星光和漂移；渐变使用显式椭圆半径并在元素边缘前完全透明，避免出现矩形裁切。设计目标是让宇宙氛围可被感知，同时保持正文、按钮和不透明学习面板清楚；这不是已通过儿童实测的注意力结论。

- 地图、课程总览和航行可轻动；认音、拼字、口语与轻复习使用静态背景，强度降至普通背景的 `.38`。所有原生弹窗（包括节点详情）和后台暂停视觉持续动效，系统减少动态效果优先。
- 家长的「轻动效 / 静态」保存为 v4 可选 `preferences.ambientMotion`，缺失按默认轻动效处理，预览修改只留在预览中。视觉开关与音乐意图分开，系统减少动态效果不会自动静音。
- 轻音乐为 16 秒原创无歌词素材，只经明确点击启动，刷新默认关闭。它在地图、课程总览和航行中以主音量的 20% 播放；课堂、家长面板、后台及录音暂停，点读示范优先，完整示范结束后才可恢复。手动暂停后不自动恢复；开启声音未成功提交时暂停音乐。
- 「声音与音乐」面板本身允许试听音乐；节点详情只暂停视觉动效，当前不额外停止音乐。不要把视觉的「所有弹窗暂停」规则误写成所有弹窗都停止音乐。

具体状态矩阵和异常恢复以 [PRD 的背景取舍](PRD.md#44-背景可见性与专注的取舍)、[声音入口与优先级](PRD.md#45-声音入口与播放优先级)及 `src/lib/useAtmosphere.ts`、`src/lib/backgroundMusic.ts` 为准。

### 3.3 当前设计决定与理由

| 问题 | 当前决定 | 理由与边界 |
|---|---|---|
| 完整星图容易挤掉目前能做的事 | 先显示航行控制台，再显示全部所选星域节点 | 让当前任务和远期好奇心都有位置；不通过隐藏未来规划伪装内容已开放 |
| 长期 48 课总量与眼前任务混在一起 | 学习首页强调本课三站，完整课序留在课程总览 | 区分课内阶段、课程单元和探索地点，避免用同一种「星球进度」表达三个概念 |
| 第 3 课的地图故事与航行缺少联系 | 找线索、拼出 `map`、口语介绍后在驾驶舱显示地图 | `MissionBrief` 与驾驶舱从已有学习完成记录派生，不再存一份物品数量，不发额外燃料 |
| 喇叭图标切换缺少可感知反馈 | 打开声音面板，分别说明声音开关和音乐播放状态 | 让操作结果可见，音乐仍需主动开启，不用自动播放作为点击反馈 |
| 本地学习记录可能丢失 | 家长可导出完整 JSON，校验并看摘要后确认替换 | 提供手动迁移与备份，不引入账号或将其称为云同步；不合并燃料余额 |

这些决定针对当前亲子使用流程。星云强度、音乐听感、任务可理解性和 iPad 性能仍需真机及儿童实测；现有浏览器检查只能验证实现行为。

## 4. 航行与燃料机制

### 4.1 当前固定奖励规则

| 行为 | 探索燃料 |
|---|---:|
| 完成新课教学 | +30 |
| 完成拼读游戏 | +20 |
| 完成情景对话 | +30 |
| 本课三阶段全部完成 | +10 |
| **完成一课合计** | **90** |

早期草案曾包含独立复习 +10、每课合计 100 的示例。当前没有独立复习燃料奖励，不能按旧草案恢复或重算历史余额；未来调整需要先设计账本迁移。

规则：
1. 奖励依据课程任务完成，不等同于已经掌握或发音准确；不惩罚做错题，口语由家长确认。
2. 同一课程的同一奖励按唯一事件 ID 防重复领取；重刷页面不能刷燃料。
3. 新节点消耗燃料；**已发现节点之间回访免费**，防止复习与探索受到限制。
4. 保持“短、中、长”三级节奏：小节点约 0.5–1 节课、普通星球约 1–2 节课、大型里程碑约 3–4 节课。
5. 关键星域由引擎等级解锁，防止到远处的体验变成无止境攒数值。
6. 若孩子长时间未达到某航点，提供支线小节点、趣味复习和阶段探索奖励；不设置连续登录惩罚。

第 4–6 条是后续节奏与星域开放的设计方向，当前没有引擎等级解锁、支线奖励或自动难度调整。整课 +10 从三阶段完成状态派生，没有独立总结提交或额外领奖按钮。

## 7. 飞船科技树与升级

| 引擎 | 对应星域 | 设计含义 | 真实性 |
|---|---|---|---|
| MK I：化学火箭 | 地月/内太阳系 | 初期小火箭 | 真实推进原理 |
| MK II：离子推进 | 巨行星/边疆 | 深空探测 | 真实推进原理；具体旅程游戏化 |
| MK III：聚变飞船 | 邻近恒星 | 星际推进升级 | 概念性方案，非成熟实用载人技术 |
| MK IV：曲速飞船 | 银河深空 | 扩展远距离星际剧情 | 科幻技术 |

除了引擎技术，外观可升级：驾驶舱、太阳能板、雷达、机械臂、着陆腿、护盾装饰、颜色/旗帜、宠物机器人。外观升级尽量让孩子直接看出区别。升级主要由课程阶段、剧情和探索成就解锁，而不是昂贵的重复付费型资源循环。

## 8. 到达节点后的内容模板

**每个重要节点至少提供“一件有趣的事”**，避免抵达后仅显示一句恭喜。

通用节点内容：
- 抵达动画与天体展示；
- 1 张真实天文知识卡（图片/比例/趣味问题，标明科学事实与科幻设定）；
- 1 个英语互动：NPC 对话、指令寻物、拼读方块合成或阅读线索；
- 1 项探索奖励与图鉴条目；
- 回访入口与复习支线。

特色任务举例：

| 节点 | 趣味事件 | 英语目标 | 奖励 |
|---|---|---|---|
| 月球 | 第一次低重力登陆 | Go / Stop / Jump | 月球旗帜 |
| 火星 | 用方块搭建第一座基地 | I need a block. | 火星基地组件 |
| 木星 | 识别大红斑与巨行星 | big / small, I can see... | 风暴徽章 |
| 木卫二 | 探索冰壳与地下海洋假说 | ice / water / under | 冰晶材料 |
| 土星 | 在行星环附近收集冰晶 | Find the blue crystal. | 环形装饰 |
| 冥王星 | 辨认矮行星及其卫星 | far / cold | 远行徽章 |
| 比邻星 | 初识光年与最近恒星 | near / far | 星际导航器 |

### 科普可信度

- “真实宇宙知识”与“游戏想象”在 UI 中明显区分。
- 星系、恒星、行星、卫星、矮行星、黑洞等分类正确。
- 宇宙尺度采用“非按真实比例”说明；必要时给真实距离、单位和科普解释。
- 动态位置、天体发现数量和分类等可变信息以后定期核验。

## 9. 星际收藏图鉴

本节为独立图鉴的长期设计。当前仅有补给先锋收藏卡、节点详情与本课故事反馈，尚未实现通用图鉴中心或首次抵达日期。

每发现一个节点点亮专属卡片，展示：
- 名称（中文/英文）、天体类别、星域。
- 真实天文图片或可靠的科普插画。
- 一条适合儿童的有趣事实和一个小问题。
- 首次抵达日期、完成的任务、获得的收藏品。
- “再去看看”按钮：**已到达节点免费回访**。

可设置可选收藏目标，例如“认识四大类天体”“收集所有巨行星的图鉴”，但不因漏一天学习取消奖励。

### 11.1 关键状态与持久化规则

- `locked`：未开放，仍可查看模糊预览。
- `available`：满足前置条件，可检查燃料并起飞。
- `traveling`：播放航行过程动画。
- `discovered`：已到达，点亮图鉴、可免费回访。
- `completed`：完成该地点核心剧情任务。
- 起飞需在同一完整存档中提交扣费、首次抵达与当前位置，成功后才显示航行动画；失败不报抵达成功。当前通过 `useProgress.ts`、`saveLock.ts` 的串行写入与原始快照冲突检查处理，不能只靠按钮禁用或读后写比较宣称跨标签页原子化。
- 本机存档导出与经摘要确认的完整替换导入已实现，包含学习、探索、复习、音量与动效偏好；校验失败不覆盖，预览禁止导入。音乐播放意图不写入备份。手动备份不能称为云同步。

## 13. MVP 验收标准

以下保留完整目标的验收标准，不表示已完成月球指令游戏、火星、引擎或独立图鉴。当前验收地月空间 9 点航行、科普详情及既有补给任务；月球指令游戏、火星互动仍待实施。

1. 孩子可在 iPad 浏览器横屏打开星际地图，明确看到当前位置、下一站和燃料余额。
2. 完成英语任务后，燃料变化正确；同一奖励无法通过刷新无限领取。
3. 燃料不足、引擎等级不足时，按钮与提示准确；满足条件则能起飞抵达。
4. 每次抵达后发生明显变化：地图标记、动画、知识卡或物品奖励。
5. 旧节点可免费回访，至少一处旧节点能够触发英语复习任务。
6. 家长能在不使用语音识别或自动评分的情况下陪伴孩子完成口语任务；可选临时录音不作为必须条件。
7. 整个系统不会因答错、离线几天或未连胜而惩罚孩子。
8. 教学与游戏界面可区分科学事实与虚构设定。

2026-11-05 最近一次实现验证为项目 12 个测试文件、82 项测试和生产构建通过；这是当次快照，不是以后必须维持的测试总数。隔离浏览器已检查三种视口、声音面板、音乐优先级、动效暂停与静态回退、预览隔离及备份恢复，详见 [PRD 验收表](PRD.md#11-验收标准与当前验证结果)。真实 iPad Safari、音乐听感、教学发音人工校对、科普资料与许可审核以及儿童实测仍未完成；不能据构建或播放成功声称这些项目通过。

## 14. 风险及设计原则

- **重复刷题**：不要以高额燃料迫使孩子机械重复；应有多样化课程、小游戏和即时目标。
- **注意力偏移**：每次航行或升级应与学习成果直接相关，避免孩子只想看动画。
- **后期经济失衡**：当前每课固定 90 燃料，历史交易不追溯改写；未来目标、费用和引擎分层需重新设计并验证迁移。
- **地图混乱**：先突出当前可操作任务，再完整展示所选星域，使用六星域切换组织长期目标，不把全部节点挤入首屏。
- **天文误解**：地图是游戏路线图，不是实际比例图；非真实设施和科幻推进系统要明显标注。
- **家庭使用优先**：让父亲成为共同探险伙伴，而非增加大量审题和管理负担。

## 15. 结论

该系统最有价值的设计不是燃料本身，而是提供持续可见、不断扩大的探索目标：**今天学会一个新声音，明天能抵达一个新世界。**

推荐开发顺序：**星图 → 燃料获取 → 飞船抵达 → 图鉴/科普 → 月球和火星互动 → 飞船升级**。先做真实可玩的垂直切片，再逐步扩展 60+ 内容节点，而不是一开始开发完整宇宙。
