## 1. 项目背景与初衷

孩子目前就读小学一年级，英语水平处于需要巩固基础的阶段。家长希望帮助孩子系统学习**自然拼读（Phonics）**，并逐渐从单词跟读过渡到简单的英语口语表达。

此前体验过线下英语机构，发现试听时较高密度的互动有吸引力，但常规大班课程可能无法保证每名孩子都获得足够的互动与开口时间；且长期课程费用较高。家长具备软件开发经验，希望自己制作一个英语学习网站，在**周末陪伴孩子完成约 60 分钟亲子学习**。

孩子对 **Minecraft、宇宙、行星与太空探索**有较强兴趣，因此产品将这些元素融入学习体验，用探索欲驱动学习，而不是把练习题简单堆成题库。

### 1.1 产品核心目标

1. **巩固自然拼读**：从字母与音素的对应关系开始，逐步学会音素合成、分解，以及阅读可解码单词。
2. **促进真实开口**：通过图片、提问、固定句型和亲子交流，让孩子尝试用英语回答，而非只点选答案。
3. **保持学习兴趣**：用 Minecraft 风格的方块、合成、星球解锁和飞船修复奖励引导孩子持续探索。
4. **提升亲子互动质量**：网站负责展示内容、播放标准音频、安排挑战和记录进度；家长负责鼓励、纠音与情境交流。
5. **低成本迭代**：先做一节完整可玩课程，验证体验，再逐步扩充内容。

### 1.2 非目标（MVP 不做）

- 不替代英语教师，也不宣称保证达到某个考试或 CEFR 级别。
- 不做 3D 开放世界、实时战斗或完整 Minecraft 游戏。
- 不做语音录制、录音回放、AI 发音评分或开放式 AI 对话。
- 不做账号体系、付费系统、排行榜、社交或复杂背包。
- 不做完全自动化的学习评价；口语完成由家长人工确认。

## 2. 用户与使用情境

### 2.1 目标用户

- **孩子**：约 6 岁，小学一年级，英语初学者，喜欢 Minecraft 和宇宙题材；需要明确、直观、低门槛的触屏操作。
- **家长**：负责陪同学习、判断口语表达、解释题意与调节节奏；同时是产品开发和内容维护者。

### 2.2 典型使用场景

家长与孩子打开网站，在同一行星球路线中看到当前进度。孩子先进入字母森林星，听字母音和图片词；完成后进入拼读沙丘星，用字母方块拼出单词；最后进入对话水晶星，根据图片尝试回答英文问题。家长确认口语练习后，三颗星球全部点亮。每一阶段都可返回地图、暂停或复习。

当前用星球发光、勾号和点亮数量反馈完成情况。飞船故事的完整呈现、能源方块、星星奖励与修复动画仍属于待实现内容。

**重要原则：网站是亲子共学工具，不是让孩子单独刷屏一小时。**

## 3. 产品定位与体验原则

### 3.1 核心体验循环

`星球地图 → 认声音 → 点亮森林 → 拼单词 → 点亮沙丘 → 开口说 → 点亮水晶 → 返回地图 / 复习`

星球点亮与学习阶段完成对应。字母学习由家长确认跟读尝试，拼读必须通过字母顺序校验，口语由家长确认孩子已尝试开口。系统不自动评判跟读和口语发音。

### 3.2 交互与教学原则

- **一次只做一件事**：每屏一个清晰的主任务。
- **高可理解性**：大按钮、明显图标、语音提示、少量文字；允许孩子自己操作。
- **鼓励优先**：错误可以重试，给予具体提示，不扣分、不强制倒计时、不制造焦虑。
- **先听音，再拼读，再表达**：不能把字母名称当成自然拼读的音素。
- **已教才能考**：独立拼读任务必须基于已经教授的字母—音素对应关系；尚未教授的词可以作为听说词汇，但不可假装孩子已经能独立解码。
- **可控制节奏**：家长随时暂停、重复播放、回到前一步。
- **不过度奖励**：鼓励尝试、纠错和口语输出，而不仅是完成题目的速度。
- **图像优先**：儿童页面突出星球、字母、图片和主要操作；移除装饰性英文标签、独立任务侧栏和多余小字。
- **解释集中**：领读提示、音频校对状态和存储说明放到「家长」入口。
- **渐进复杂度**：当前全部操作以点按完成，拖动后置。

## 4. 视觉与交互规范

### 4.1 当前风格

保留 Minecraft 方块宇宙方向，采用原创 SVG 方块星球和单词插图。界面使用深空蓝背景、大图、大字和明确的按钮，减少装饰元素。字体使用本地化 Nunito 与系统中文字体，不依赖外部字体请求。

### 4.2 当前设计规范

| 项目 | 当前方案 |
|---|---|
| 主要终端 | iPad Safari 横屏，兼容鼠标、触屏和键盘 |
| 检查视口 | 1194 × 834、1024 × 768 横屏；390 × 844 窄屏 |
| 页面背景 | 深空蓝 `#132138` |
| 正向操作 | 浅绿 `#A6DBB6`；按钮采用同色系变体 |
| 当前星球 | 金色 `#F3CE78` 边框与入口 |
| 学习面板 | 浅米色 `#F5F3E8` |
| 完成星球 | 发光、绿色勾号及「已点亮」文字，不能只靠颜色区分 |
| 未解锁星球 | 图像变暗、锁图标及具体先备条件 |
| 主操作 | 关键点按区域至少 48 × 48 CSS px |
| 字母与例词 | 字形清晰、足够大；图片卡整体可点读 |
| 动态反馈 | 轻量按压、发光及播放高亮；尊重减少动态效果偏好 |

### 4.3 信息简化原则

- 首页将当前全部三颗星球放在同一行，直接展示学习顺序、完成情况和入口。
- 不再使用星图轨道、右侧任务卡、重复的导航入口、英文装饰标签和页脚口号。
- 字母课堂突出一个大字母与三个图片词；提示只保留「点字母听发音，点图片听单词」。
- 家长说明集中在顶部「家长」面板；窄屏下使用带可访问名称的图标入口。
- 家长面板提供会话级预览开关。开启后可直接进入已实现的第 1–8 课及任一课内阶段；预览中的完成、草稿和燃料变化不写入正式存档，关闭后恢复真实学习进度。第 9–48 课仍保持准备中。
- 顶部提供全屏图标。支持 Fullscreen API 的浏览器可直接进入/退出全屏；iPad Safari 不支持或拒绝调用时，展示「分享 → 添加到主屏幕」步骤。从主屏幕启动使用 iOS 独立窗口并隐藏 Safari 顶部栏。
- 使用响应式布局和安全区域。窄屏地图仍保持三颗星球同排，课堂将大字母与三张词卡分行排列。

## 5. 信息架构与星球路线

课程总览展示 6 个单元、48 课的完整路径。当前实现「字母启航」第 1–8 课，第 9–48 课标注「准备中」，不能进入。第 17–48 课只展示课程设计中的阶段方向，具体课次内容待细化。

首页显示「当前学到第 N 课」、已完成课数与当前查看的课次。点击「全部课程」查看完整路径；从总览可继续当前课或复习已完成课。每课内部仍是同排的三个星球：

```text
课程总览（6 单元 / 48 课）→ 选择已开放课次
  └── 本课星球地图（已点亮 N / 3）
        ├── 字母森林：本课所有字母完成 → 开放沙丘
        ├── 拼读沙丘：本课所有拼读题通过 → 开放水晶
        └── 对话水晶：家长确认尝试开口 → 完成本课、解锁下一课
```

三个星球是课内阶段，与课程设计中的六大单元不同。前 8 课完成后可复习，第 9 课仍为准备中，不伪装成已开放内容。

| 课次 | 新字母音 | 拼读题 | 口语问答 |
|---|---|---|---|
| 1 | s / a / t | at、sat | 宇宙商店：Hello / I want… / Thank you / Bye |
| 2 | p / i / n | pin、sit、tap | What is it? → It's a pig. |
| 3 | m / d | map、mad、dip | What is it? → It's a map. |
| 4 | 复习前 8 个音 | map、pin、pan、mat 场景归位 | What do you see? → I see a map. |
| 5 | o / c / k | cot、cop、kid | What do you see? → I see a cat. |
| 6 | e / h / r | hen、red、pet | What do you like? → I like the hen. |
| 7 | b / g / u | bug、big、mug | Is it big or small? → It's a big bug. |
| 8 | 复习全部 17 个音 | cat、dog、mug、hat、bed、map、sun、rug 场景归位 | What do you see? / Where is the map? / Are we ready? |

当前六个页面视图为课程总览、星球地图、字母课堂、拼读挑战、口语挑战、星际航行。课堂顶部持续显示课次；点亮反馈使用共享弹窗，尚无独立奖励结算页。

`page` 状态由 React 管理，当前未使用独立 URL 路由。刷新后恢复本机保存的页面与学习状态。

## 6. 页面与完成规则

### 6.1 P01 — 星球地图（已实现）

**目标**：一眼看清全部星球、当前可进入哪一站，以及已经完成到哪里。

**布局**：顶部显示当前学到的课次、已完成课数、「全部课程」入口、本课字母和「已点亮 N / 3」；下方三张大星球卡横向排列，顺序固定为森林、沙丘、水晶。每张卡包含序号、图像、名称、活动名称和操作入口。

| 状态 | 表现 | 操作 |
|---|---|---|
| `current` | 金色边框、「到这里啦」和突出入口 | 开始或继续当前阶段 |
| `completed` | 星球发光、勾号、「已点亮」 | 再玩一次，保留完成记录 |
| `locked` | 图像变暗、锁图标、先备条件 | 查看说明，前往先备阶段 |

完成数量由三个阶段的完成记录计算，不作为可累加奖励存储。全部完成后，地图显示「3 / 3 已点亮」。本课完成后提供继续下一课的入口；所有已实现课程完成后提供查看路径入口。

### 6.2 P02 — 字母森林星：认声音（已实现）

**布局**：顶部显示当前字母及本课步骤按钮；主面板左侧为大字母点读方块，右侧为三张图片词卡；底部为「上一个」和确认继续按钮。

**交互**：

1. 点按大字母播放对应音素，不播放字母名称；音素同时以 IPA 显示。
2. 点按任意图片词卡播放整词，可反复点读；播放时高亮当前卡片。
3. 家长在孩子尝试跟读后点击「读好了，下一个」。后续字母按完成顺序开放，已开放步骤可返回复习。
4. 最后一个字母点击「学好了，点亮星球」后，返回地图并显示森林点亮弹窗，提供沙丘入口。

第 1、2、5、6、7 课各有三个新音步骤，第 3 课有两个。第 4、8 课的森林改为飞船场景声音扫描：播放当前目标音，孩子点击以该声音开头的物品；连续两次错误后高亮目标，不扣分。第 4 课一组复习 8 音，第 8 课分两组复习全部 17 音。旧版已完成记录继续有效。

**教学边界**：每个音素对应三个听说拓展词，但不要求孩子独立解码全部听说例词。领读细节和试听音频说明放在「家长」面板。

### 6.3 P03 — 拼读沙丘星：拼单词（已实现）

**开放条件**：本课森林的全部字母步骤均已完成。

**内容**：第 1–3、5–7 课继续使用听音点字母拼词。第 4 课将 `map/pin/pan/mat` 放回迫降舱物体；第 8 课分两批归位 `cat/dog/mug/hat` 与 `bed/map/sun/rug`。归位词只使用累计已教规则。

场景归位同时支持拖放和「先点单词、再点物体」，不能依赖拖动才能完成。双语备选词卡将喇叭合并到卡片内，点击整卡同时点读并选中；正确后单词吸附到物体并播放整词，归位后的场景卡点击图片、英文或中文都可重播。错误后原位保留，连续两次错误高亮目标，不扣分。当前批全部完成后才进入下一批或点亮沙丘；刷新后恢复批次和已归位词。

复习单元中的备选词、归位标签、机器人问题和示范回答均同时显示英文与中文；中文只帮助理解，不作为独立拼读目标。

**交互**：

1. 点击「听单词」，按需重播目标词。
2. 点击候选字母，按顺序填入空格；候选方块按数量消耗，已用方块不可重复选择。声音开启时，选字母会播放该音素。
3. 校验前可以点按已填格子移除字母，或点击「重新放」清空。
4. 填满后点击「拼好了」。字母顺序不匹配时提示「再听一次，换一换方块」，保留重试入口，不扣分。
5. 拼对后显示正确反馈和该词的中文意思；声音开启时播放完整词。点击「下一个单词」进入下一题。
6. 本课所有题目均拼对后，满足沙丘完成条件。点击「点亮星球」返回地图并显示点亮弹窗，可前往水晶星。

保存当前题目、已通过题目和未提交的字母排列；刷新后可续玩。已点亮后重玩会重置本次题目与排列，但保留历史完成状态。

### 6.4 P04 — 对话水晶星：开口说（已实现）

**开放条件**：本课沙丘全部题目已拼对。

**第一课：宇宙商店情景对话**

入口仍是第一课「对话水晶星」。单屏展示机器人店主、柜台与商品、可点读字幕和底部家长操作，没有独立任务侧栏。

1. 问候：`Hello! Welcome to my shop!` → `Hello!`。
2. 购买：`What do you want?` → `I want an apple, please.` 或 `I want a gem, please.`。家长确认本轮尝试后，才可选择苹果或宝石。
3. 感谢：店主按选择递交物品，孩子练习 `Thank you!`。
4. 告别：`You're welcome! Have a great trip!` → `Bye!`。

支持「跟着说 / 关键词 / 自己说」，提示等级可随时切换。父母可用「家长帮我说」推进，记录协助节点，不扣物品。音频均由点按触发，字幕在静音或播放失败时仍可用；不录音、不自动评分。

完成四轮后，在当前页面回顾目标句子和本次补给。每种物品只收集一份，重玩或刷新不累计重复数量。点击「完成对话，点亮星球」才提交本课口语完成并开放下一课；旧版首课已完成记录保持有效。可重玩另一分支，历史课程完成不撤销。

**第 2、3、5–7 课：单句问答**

使用小猪、地图、小猫、母鸡和小虫等图片，练习 `What is it?`、`What do you see?`、`What do you like?` 和大小描述。家长确认孩子尝试开口后点亮水晶星。

**第 4、8 课：场景对话**

复用森林和沙丘的飞船场景以及已归位物体。第 4 课练习一轮 `What do you see? → I see a map.`；第 8 课练习三轮 `What do you see?`、`Where is the map?`、`Are we ready?`。每轮可点读机器人问题和示范回答，目标物体高亮；点击场景物体的图片或双语标签均可播放对应单词。家长逐轮确认后点亮水晶星。

以上均只记录家长确认，不代表发音准确或已经掌握。

### 6.5 共享点亮弹窗（已实现）

完成一站后展示对应星球的发光图像、勾号和「点亮啦」标题。前两站提供「去下一颗星球」与「回到星球地图」；最后一站显示本课完成；第 1–7 课提供下一课入口，第 8 课显示字母启航全部完成。所有课都保留返回地图入口。

重复学习不重复累计点亮数量。点亮只是阶段完成反馈；商店收集的苹果和宝石单独记录，不等同于星星、能源方块或飞船部件。

### 6.6 星际航行首轮（已实现）

## 7. 首个课程内容（Mission 01）

配置保留课程标识 `mission-001` 和名称「失落的能源方块」。当前先跑通三站学习，飞船迫降与能源修复的完整剧情尚未呈现。

### 7.1 字母音与三个例词

| 字母 | 音素 | 三个听说拓展词 | 图片内容 |
|---|---|---|---|
| s | /s/ | sun / snake / sock | 太阳 / 蛇 / 袜子 |
| a | /æ/ | apple / ant / alligator | 苹果 / 蚂蚁 / 短吻鳄 |
| t | /t/ | top / tiger / turtle | 陀螺 / 老虎 / 海龟 |

短 /æ/ 的例词采用美式英语。每个例词都有独立图片和整词音频；每个字母有独立音素音频。例词用于听说和建立声音联系，不作为独立拼读考题。

### 7.2 拼读与口语

- 拼读顺序：先由 /æ/、/t/ 合成 `at`，再由 /s/、/æ/、/t/ 合成 `sat`。
- 这两个词的字母均已在森林教授。`at`、`sat` 的含义不作为本轮独立考核重点。
- 口语使用宇宙商店四轮对话，练习问候、请求物品、感谢与告别。`gem` 及完整句型属于听说内容，不作为已学拼读规则考题。
- 只学 s / a / t 不足以独立解码 `cat`、`sun` 或大多数拓展词。第 2–8 课按累计教授的音形规则扩充拼读题，不能把听说例词直接当成可解码题。

### 7.3 节奏安排

周末约一小时是亲子共学场景的参考，不是当前三站原型的固定课时，也不是必须连续使用屏幕的时长。当前没有倒计时或强制学习时长。

家长可在字母学习、拼读与口语之间安排离屏休息、重复示范和额外交流。优先观察孩子的参与状态，可以分几次完成。

### 8.1 课程配置

课程内容与页面渲染分离，配置位于 `src/data/lesson.ts`，使用 TypeScript 类型约束。

| 配置 | 当前用途 |
|---|---|
| `lessons` | 前 8 课配置，每课有稳定 ID、字母或复习步骤、拼读题和口语任务 |
| `steps[].words` | 每音三个听说词，显式标注 `oral_only` |
| `blendRounds` | 拼读题标注 `decodable` 与所需规则 `requires`；测试核对累计已教规则 |

当前八课的字素均为单字母。规则依赖检查覆盖这些已实现课，不代表已具备任意复杂词汇的自动音素分析能力。

### 8.2 本机保存的数据

进度保存在 `localStorage`。为兼容首版，键名继续使用 `tom-phonics-progress-v1`，数据内部版本为 `version: 4`；不要仅为匹配版本号而直接更换键名。

| 字段 | 含义 |
|---|---|
| `version` | 当前状态结构版本，值为 4 |
| `space` | 全局探索位置、交易事件、空间站步骤与收藏；不随课次切换重置 |
| `lessonIndex` | 当前查看的课次索引，0–7 |
| `records` | 其他课的独立进度，按稳定课程 ID 保存；当前课在顶层字段保存 |
| `page` | `courses`、`map`、`lesson`、`blending`、`speaking`、`space` |
| `step` | 本课当前字母步骤索引，按课程长度校验 |
| `completed` | 已完成字母步骤索引集合 |
| `volume` | 示范音量偏好，范围 0–1；0 表示静音 |
| `blendRound` | 本课当前拼读题索引，按题目数量校验 |
| `blendCompleted` | 已通过拼读题索引集合 |
| `blendDraft` | 当前排列中的字母 |
| `blendSolved` | 当前排列是否已经通过校验 |
| `speakingCompleted` | 家长是否已确认口语练习完成 |
| `reviewSounds` | 第 4、8 课本次声音扫描已完成的步骤 |
| `reviewPlacements` | 第 4、8 课本次已归位的单词索引 |
| `reviewDialogueStep` | 第 4、8 课当前场景对话轮次 |
| `dialogue`（可选） | 第一课的节点、提示、确认、商品分支、完成与协助节点、去重物品集合 |

当前保存燃料交易、商店去重物品和空间站收藏，不保存录音或发音评分。存储不可用时显示提示，页面仍可操作，但关闭后可能无法续学。更换设备、浏览器或清除网站数据后，记录不会自动同步。

家长预览使用独立的 React 内存状态，不增加存储字段，也不调用正式保存入口。预览选课和直接进入沙丘、水晶只补齐沙盒内的先备状态，不能改变 `courseUnlocked`、正式点亮记录或奖励账本。

### 8.3 点亮与开放条件

`src/lib/progress.ts` 统一负责状态解析、阶段完成判断、点亮计数和进入页面的条件。

| 星球 | 开放条件 | 点亮条件 |
|---|---|---|
| 森林 | 所在课程已开放 | 本课全部字母步骤完成 |
| 沙丘 | 森林已完成 | 本课全部拼读题通过校验 |
| 水晶 | 森林和沙丘均已完成 | 家长确认口语练习完成 |

课程 1 默认开放；下一课必须在此前所有课的三个阶段完成后才开放，并且已有实现内容。完成只代表任务完成，不等同于掌握。

点亮数量通过 `litCount` 从阶段完成状态派生。复习不清除历史完成记录；锁定阶段不能通过正常导航提前进入。

### 8.4 旧版兼容与恢复

- v1/v2/v3 均迁移到 v4；旧有效阶段奖励自动补齐。恢复时只接纳有效课程事件和合法空间站首次扣费，去除重复/无效事件，不产生负余额。
- `useProgress.ts` 提交同一份完整存档；Web Locks 或 IndexedDB 事务串行化写入，写入前比对保存快照。冲突时载入最新状态并提示再操作。
- 航行和领取保存失败时保留原探索状态，不播放成功抵达；普通学习可保留内存进度并提示保存不可用。


- 内部升级 v4，保留可选 `dialogue` 缺失时从问候开始，旧口语完成不回退。对话状态按课程归档，不能带入第二课。无有效购买分支时不恢复后续节点；未完成沙丘时不恢复对话。
- 第 4、8 课新增复习草稿字段但不升级数据版本；缺少字段的旧版已完成复习记录按原题数校验后迁移为新场景三阶段已完成，不重新锁课或重复发燃料。旧版未完成复习可从新场景重新开始。

- 兼容 `version: 1` 和 `version: 2`，将旧进度迁移到第 1 课，保留音量、完成记录和有效拼读草稿；旧版只完成森林不算整课完成。
- v2 已完成整课时开放第 2 课，不授予第 2、3 课的完成记录。切换课程保存各课进度，复习不撤销后续课程的解锁。
- 旧版森林的第 4 步是 `sat` 示范。迁移后保留前三个字母记录；已有森林完成记录会使森林点亮并开放沙丘，但不会自动把两道新拼读题算作通过。
- 若旧版停留在森林第 4 步，迁移后返回地图，展示新的下一站入口。
- 新版恢复时清理无效索引、重复记录和不属于当前题目的字母；当前题目的通过标记须与排列及已通过题目记录一致。
- 缺失、无法解析或不支持版本的数据回退到初始状态。缺少先备阶段时，不恢复下游完成状态或进入下游页面。

## 9. 当前技术架构与开发方式

### 9.1 已采用的技术

- **应用**：React + TypeScript + Vite，页面视图由 `App.tsx` 中的状态切换。
- **样式**：原生 CSS、CSS 自定义属性和媒体查询，当前没有引入 Tailwind CSS。
- **图像与图标**：项目内原创 SVG，界面图标使用 `lucide-react`。
- **交互**：标准按钮点按，支持键盘焦点；第 4、8 课词语归位额外支持 Pointer Events 拖放，但始终保留点按替代操作。
- **声音**：本地 MP3，通过 `HTMLAudioElement` 按需播放。切换页面、步骤或音量时停止当前音频；新播放替换旧播放，并处理失败与静音提示。
- **状态**：React 状态 + `localStorage`，包含旧版迁移和重复完成幂等处理。
- **测试**：Vitest 验证状态逻辑；浏览器检查验证交互与响应式布局。
- **交付**：可运行的本地原型和 Vite 静态构建。已提供 Web App Manifest、iOS 主屏幕图标和独立显示配置；HTTPS 托管、离线缓存与云同步尚未实现。

### 9.3 音频开发与验收边界

当前共有 115 段本地 MP3。场景复习新增 `mat`、`rug` 两个整词及第 8 课后两轮对话的 4 段句子音频；重复使用的单词和问题复用原文件。音素生成器校验 eSpeak 事件，但全部素材仍待人工校对。

- 音素用 eSpeak-NG 的显式音素输入生成，脚本校验 IPA 事件是否为本课目标音，包括前 8 个音及新增 /ɑ/、/k/、/ɛ/、/h/、/r/、/b/、/ɡ/、/ʌ/。c 与 k 分别保留素材文件，但都教授 /k/；短 o 原型需重点人工校对。
- 整词与句子使用 macOS Samantha 合成；全量生成脚本需要 macOS 的 `say` 和 FFmpeg，运行网站本身不需要这些工具。
- 音频路径配置在 `src/data/lesson.ts`，替换素材不需要修改页面。
- 音素事件校验、文件能加载和能播放都不能替代人工试听。当前所有音频仍按待人工校对的原型试听素材管理，「家长」面板明确说明这一状态。
- 正式教学素材需人工确认音素与单词发音，特别是短 /æ/、/ɪ/ 及辅音不附加元音，以及整词合成。

### 9.4 iPad 兼容性重点

- 横屏优先，按 CSS 视口响应式布局并考虑安全区域；不依赖鼠标悬停。
- 所有学习步骤可通过点按完成，主要目标至少 48 × 48 CSS px。
- 音频由用户操作触发，支持重复播放和静音；iPad 实际音量也可用设备音量键调整。
- 浏览器支持时可由顶部按钮直接全屏；iPad Safari 顶部栏无法直接隐藏时，使用主屏幕独立窗口。该模式当前仍依赖可访问的开发服务或线上站点，不支持离线运行。
- 页面、当前学习步骤和拼字草稿可从本机记录恢复。
- 已完成桌面浏览器的 iPad 尺寸检查，仍须在真实 iPad Safari 上验证触屏、播放、布局和性能。
