## 1. 项目背景与初衷

孩子目前就读小学一年级，英语水平处于需要巩固基础的阶段。家长希望帮助孩子系统学习**自然拼读（Phonics）**，并逐渐从单词跟读过渡到简单的英语口语表达。

此前体验过线下英语机构，发现试听时较高密度的互动有吸引力，但常规大班课程可能无法保证每名孩子都获得足够的互动与开口时间；且长期课程费用较高。家长具备软件开发经验，希望自己制作一个英语学习网站，在**周末陪伴孩子完成约 60 分钟亲子学习**。

孩子对 **Minecraft、宇宙、行星与太空探索**有较强兴趣，因此产品将这些元素融入学习体验，用探索欲驱动学习，而不是把练习题简单堆成题库。

### 1.1 产品核心目标

1. **巩固自然拼读**：从字母与音素的对应关系开始，逐步学会音素合成、分解，以及阅读可解码单词。
2. **促进真实开口**：通过图片、提问、固定句型和亲子交流，让孩子尝试用英语回答，而非只点选答案。
3. **保持学习兴趣**：用 Minecraft 风格的方块、合成、星球解锁和飞船修复奖励引导孩子持续探索。
4. **提升亲子互动质量**：网站负责展示内容、播放标准音频、安排挑战和记录进度；家长负责鼓励、纠音与情境交流。
5. **低成本迭代**：先做一节完整可玩课程，验证体验，再逐步扩充内容。

### 1.2 非目标（MVP 不做）

- 不替代英语教师，也不宣称保证达到某个考试或 CEFR 级别。
- 不做 3D 开放世界、实时战斗或完整 Minecraft 游戏。
- 不做语音识别、AI 发音评分或开放式 AI 对话；口语练习只提供本轮临时录音回放，不上传或写入存档。
- 不做账号体系、付费系统、排行榜、社交或复杂背包。
- 不做完全自动化的学习评价；口语完成由家长人工确认。

## 2. 用户与使用情境

### 2.1 目标用户

- **孩子**：约 6 岁，小学一年级，英语初学者，喜欢 Minecraft 和宇宙题材；需要明确、直观、低门槛的触屏操作。
- **家长**：负责陪同学习、判断口语表达、解释题意与调节节奏；同时是产品开发和内容维护者。

### 2.2 典型使用场景

家长与孩子打开网站，在同一行星球路线中看到当前进度。孩子先进入字母森林星，听字母音和图片词；完成后进入拼读沙丘星，用字母方块拼出单词；最后进入对话水晶星，根据图片尝试回答英文问题。家长确认口语练习后，三颗星球全部点亮。每一阶段都可返回地图、暂停或复习。

当前用星球发光、勾号和点亮数量反馈完成情况。飞船故事的完整呈现、能源方块、星星奖励与修复动画仍属于待实现内容。

**重要原则：网站是亲子共学工具，不是让孩子单独刷屏一小时。**

## 3. 产品定位与体验原则

### 3.1 核心体验循环

`星球地图 → 认声音 → 点亮森林 → 拼单词 → 点亮沙丘 → 开口说 → 点亮水晶 → 返回地图 / 复习`

星球点亮与学习阶段完成对应。字母学习由家长确认跟读尝试，拼读必须通过字母顺序校验，口语由家长确认孩子已尝试开口。系统不自动评判跟读和口语发音。

### 3.2 交互与教学原则

- **一次只做一件事**：每屏一个清晰的主任务。
- **高可理解性**：大按钮、明显图标、语音提示、少量文字；允许孩子自己操作。
- **鼓励优先**：错误可以重试，给予具体提示，不扣分、不强制倒计时、不制造焦虑。
- **先听音，再拼读，再表达**：不能把字母名称当成自然拼读的音素。
- **已教才能考**：独立拼读任务必须基于已经教授的字母—音素对应关系；尚未教授的词可以作为听说词汇，但不可假装孩子已经能独立解码。
- **可控制节奏**：家长随时暂停、重复播放、回到前一步。
- **不过度奖励**：鼓励尝试、纠错和口语输出，而不仅是完成题目的速度。
- **图像优先**：儿童页面突出星球、字母、图片和主要操作；移除装饰性英文标签、独立任务侧栏和多余小字。
- **解释集中**：领读提示、音频校对状态和存储说明放到「家长」入口。
- **渐进复杂度**：当前全部操作以点按完成，拖动后置。

## 4. 视觉与交互规范

### 4.1 当前风格

保留 Minecraft 方块宇宙方向，采用原创 SVG 方块星球和单词插图。界面使用深空蓝背景、大图、大字和明确的按钮，减少装饰元素。字体使用本地化 Nunito 与系统中文字体，不依赖外部字体请求。

### 4.2 当前设计规范

| 项目 | 当前方案 |
|---|---|
| 主要终端 | iPad Safari 横屏，兼容鼠标、触屏和键盘 |
| 检查视口 | 1194 × 834、1024 × 768 横屏；390 × 844 窄屏 |
| 页面背景 | 深空蓝 `#132138` |
| 正向操作 | 浅绿 `#A6DBB6`；按钮采用同色系变体 |
| 当前星球 | 金色 `#F3CE78` 边框与入口 |
| 学习面板 | 浅米色 `#F5F3E8` |
| 完成星球 | 发光、绿色勾号及「已点亮」文字，不能只靠颜色区分 |
| 未解锁星球 | 图像变暗、锁图标及具体先备条件 |
| 主操作 | 关键点按区域至少 48 × 48 CSS px |
| 字母与例词 | 字形清晰、足够大；图片卡整体可点读 |
| 动态反馈 | 稀疏星光与边缘星云；课堂静止，点亮时一次短发光；家长可关闭，尊重减少动态效果偏好 |

### 4.3 信息简化原则

- 首页将当前全部三颗星球放在同一行，直接展示学习顺序、完成情况和入口。
- 不再使用星图轨道、右侧任务卡、重复的导航入口、英文装饰标签和页脚口号。
- 字母课堂突出一个大字母与三个图片词；提示只保留「点字母听发音，点图片听单词」。
- 家长说明集中在顶部「家长」面板；窄屏下使用带可访问名称的图标入口。
- 家长面板提供会话级预览开关。开启后可直接进入已实现的第 1–16 课及任一课内阶段；预览中的完成、草稿和燃料变化不写入正式存档，关闭后恢复真实学习进度。第 17–48 课仍保持准备中。
- 顶部提供全屏图标。支持 Fullscreen API 的浏览器可直接进入/退出全屏；iPad Safari 不支持或拒绝调用时，展示「分享 → 添加到主屏幕」步骤。从主屏幕启动使用 iOS 独立窗口并隐藏 Safari 顶部栏。
- 使用响应式布局和安全区域。窄屏地图仍保持三颗星球同排，课堂将大字母与三张词卡分行排列。
- 星空与声音使用独立控制，具体状态与取舍见 [4.4](#44-背景可见性与专注的取舍) 和 [4.5](#45-声音入口与播放优先级)。
- 页面和任务切换时将焦点移到新任务标题，轻复习移到当前练习内容；弹窗打开期间不抢焦点，关闭时恢复触发按钮，原按钮已移除时回到任务标题。

### 4.4 背景可见性与专注的取舍

背景增强回应了两类反馈：大面积深蓝底缺少宇宙氛围；第一轮星云位置过于靠外且透明度过低，实际只看得到少量白点。当前以蓝青云团、紫色云团和下方云带形成三层纵深，提高星光亮度，并将云层主体移入横屏与窄屏视口。增强的目标是让背景可感知，同时使字母、图片和当前操作继续占据主要视觉位置；这仍是待儿童实测检验的设计目标。

星空背景沿用原生 CSS 渐变和原创 SVG，不使用 GIF 资源、粒子引擎或 3D 框架。星云与星光的循环仅改变位移、缩放和透明度；固定星点位置避免学习状态变化时重新散布。每层径向渐变在元素边缘前完全透明，防止出现矩形裁切边。背景覆盖整个视口，处于内容后方，不接收点击，不改变学习面板的不透明底色或全屏操作。

当前横屏为 24 颗星，窄屏为 12 颗；星云漂移周期约 18–26 秒。认音、拼字、口语和轻复习将背景整体透明度降至 `0.38` 并静止。参数用于描述当前实现，后续调整以可见性、文字对比和真机性能为依据，不作为教学效果指标。

家长在「轻动效 / 静态」中选择；缺少偏好的旧存档默认轻动效。系统减少动态效果、后台状态以及所有原生弹窗（含星域节点详情）优先暂停持续视觉动效。路线流动和飞船悬浮共用控制；手动静态及系统减少动态效果也关闭装饰性点亮动画。普通点亮反馈只有一次短发光，不延迟下一步按钮。`preferences.ambientMotion` 经统一入口保存，预览中的调整仅作用于预览内存。

拼对 `hen`、`bug`、`box`，或家长记录含这些词的复习短语后，另有一段约 2.6 秒的「单词活过来」卡片。它只在成功之后出现，不改动拼字板、不自动揭晓未完成的答案，也不延迟下一步。静态偏好、系统减少动态效果或 WebGL 不可用时改为静止插图；页面隐藏或其他弹窗打开时暂停绘制，动画结束即停止渲染。

### 4.5 声音入口与播放优先级

旧喇叭只切换静音，页面未播放示范时没有可感知的反馈，用户容易把它理解成音乐播放按钮。因此右上角入口改为打开「声音与音乐」面板，明确呈现声音开启/关闭、音乐准备/播放/暂停/失败状态，并提供「播放背景音乐」「暂停背景音乐」和失败重试。音量滑块保留在家长面板；关闭声音同时静音示范和音乐。

背景音乐采用本地原创无歌词循环和声，音量为主音量的 20%，默认关闭。它用于可选的宇宙氛围，不作为教学发音、任务完成条件或奖励。用户主动开启后，只在本次页面会话内保留播放意图；刷新不自动加载或播放。主动暂停会清除意图，之后的页面切换不能自行重启。静音、临时离开允许播放的页面或教学示范打断则保留意图，在满足条件后恢复。

视觉动效和音乐的暂停范围有区别，不能共用一个「正在播放」状态：

| 场景或操作 | 星空、路线与飞船悬浮 | 背景音乐 |
|---|---|---|
| 星球地图、课程总览、航行 | 偏好允许时轻动效 | 主动开启且未静音时可播放 |
| 认音、拼字、口语、轻复习 | 减弱并静止 | 暂停；返回允许页面后按原意图恢复 |
| 地图或航行中的「声音与音乐」面板 | 暂停 | 允许试听和控制，关闭面板可继续 |
| 家长、全屏引导、锁定或点亮弹窗 | 暂停持续动效；点亮可有一次短发光 | 暂停 |
| 星域节点详情弹窗 | 暂停 | 当前可继续；详情弹窗不改变航行页面的音乐许可 |
| 页面切到后台 | 暂停 | 暂停，返回后按原意图恢复 |
| 用户选择静态或系统减少动态效果 | 静态 | 不因此改变声音开关或播放意图 |
| 拼对 hen / bug / box 后的单词卡片 | 仅卡片内约 2.6 秒；静态或减少动态效果时改为插图；其他弹窗或后台暂停 | 不影响音乐 |
| 点读示范、逐音序列或请求麦克风 | 沿用所在页面规则 | 教学与录音优先，暂停音乐；无忙碌音频后才可恢复 |
| 用户关闭声音 / 主动暂停音乐 | 不影响视觉偏好 | 前者静音并保留音乐意图；后者清除意图 |

静音时「开启声音并播放音乐」在同一用户操作中请求播放，再经统一入口保存主音量。如果开启声音因存储失败或其他页面冲突未提交，则暂停本次音乐，避免界面仍静音但实际发声。底层音频活动订阅保证音乐不与示范或录音竞争；连续逐音示范结束后才恢复，不在每个音之间反复插入音乐。代码边界见 `src/lib/audio.ts`、`src/lib/backgroundMusic.ts` 与 `src/lib/useBackgroundMusic.ts`。

## 5. 信息架构与星球路线

课程总览展示 6 个单元、48 课的完整路径，但默认只展开当前单元，已开发课程全部完成时默认展开最近单元。六个单元入口和课次范围始终保留，其他单元可按需展开；「展开全部 48 课」可查看完整规划，「收起其他单元」回到当前单元。折叠只影响展示，不改变选课、逐课解锁或复习状态。

当前实现「字母启航」和「单词矿场」第 1–16 课，第 17–48 课标注「准备中」，不能进入。第 17–48 课只展示课程设计中的阶段方向，具体课次内容待细化。单元栏提供明确的展开状态、可访问名称和旋转箭头，窄屏仍保留完整操作入口。

## 6. 页面与完成规则

### 6.1 P01 — 星球地图（已实现）

**目标**：一眼看清全部星球、当前可进入哪一站，以及已经完成到哪里。

**布局**：以本课任务标题和当前阶段为视觉中心。课次、目标声音、已完成课数及「全部课程」放在次要位置；首页强调「本课三站」，48 课完整规划保留在课程总览。「驾驶飞船」保留入口并降低视觉权重。「已点亮 N / 3」持续可见。三张星球卡仍横向排列，顺序固定为森林、沙丘、水晶；每张卡包含序号、图像、名称、活动名称和操作入口。已完成站的复习按钮与当前站主按钮采用不同层级。

|---|---|---|

| `completed` | 星球发光、勾号、「已点亮」 | 再玩一次，保留完成记录 |

### 6.2 P02 — 字母森林星：认声音（已实现）

**布局**：顶部显示当前字母及本课步骤按钮；主面板左侧为大字母点读方块，右侧为三张图片词卡；底部为「上一个」和确认继续按钮。

**交互**：

1. 点按大字母播放对应音素，不播放字母名称；音素同时以 IPA 显示。
2. 点按任意图片词卡播放整词，可反复点读；播放时高亮当前卡片。
3. 家长在孩子尝试跟读后点击「读好了，下一个」。后续字母按完成顺序开放，已开放步骤可返回复习。
4. 最后一个字母点击「学好了，点亮星球」后，返回地图并显示森林点亮弹窗，提供沙丘入口。

第 1、2、5、6、7 课各有三个新音步骤，第 3、9–11 课各有两个，第 12 课有三个字素步骤。第 13–16 课复习已教音形。第 4、8 课的森林改为飞船场景声音扫描：播放当前目标音，孩子点击以该声音开头的物品；连续两次错误后高亮目标，不扣分。第 4 课一组复习 8 音，第 8 课分两组复习全部 17 音。旧版已完成记录继续有效。

第 1–16 课的图片词卡在中文释义旁显示单词的美式英语音标。

**教学边界**：每个音素对应三个听说拓展词，但不要求孩子独立解码全部听说例词。领读细节和试听音频说明放在「家长」面板。

### 6.3 P03 — 拼读沙丘星：拼单词（已实现）

**开放条件**：本课森林的全部字母步骤均已完成。

**内容**：第 1–3、5–7、9–16 课使用听音点字素方块拼词。第 4 课将 `map/pin/pan/mat` 放回迫降舱物体；第 8 课分两批归位 `cat/dog/mug/hat` 与 `bed/map/sun/rug`。归位词只使用累计已教规则。

场景归位同时支持拖放和「先点单词、再点物体」，不能依赖拖动才能完成。双语备选词卡将喇叭合并到卡片内，点击整卡同时点读并选中；正确后单词吸附到物体并播放整词，归位后的场景卡点击图片、英文或中文都可重播。错误后原位保留，连续两次错误高亮目标，不扣分。当前批全部完成后才进入下一批或点亮沙丘；刷新后恢复批次和已归位词。

复习单元中的备选词、归位标签、机器人问题和示范回答均同时显示英文与中文；单词附有美式英语音标，句子不标音标。中文只帮助理解，不作为独立拼读目标。

**交互**：

1. 点击「听单词」，按需重播目标词。
2. 点击候选字母，按顺序填入空格；候选方块按数量消耗，已用方块不可重复选择。声音开启时，选字母会播放该音素。
3. 校验前可以点按已填格子移除字母，或点击「重新放」清空。
4. 填满后点击「拼好了」。首次顺序不匹配时提示「再听一次，换一换方块」；本题第二次未通过后，静态突出「一起合音」，提示孩子主动听声音顺序。静音时改为请家长领读。提示不自动播放、不自动填字、不扣分；换题、离开或刷新后重置本次错误次数，拼字草稿照常保存。检查进行中阻止重复提交。
5. 第 1 课拼对后，在同一页将候选字母区替换为大字词块，任务从「听声音，拼单词」切换为「看单词，自己读」。孩子可点读每个字素、选择「一起合音」或「听整词」，再由自己尝试朗读；此状态不显示音标，避免继续依赖符号提示。点击「读过了，下一个／读过了，点亮星球」进入下一题或完成沙丘。其他常规课保留原正确反馈、中文释义、美式英语音标及「下一个单词」流程。
6. 本课所有题目均拼对后，满足沙丘完成条件。首课的看词朗读是拼对后的练习与家长陪伴提示，不增加额外完成判定，不识别语音或自动评分。
7. 第 6 课的 `hen`、第 7 课的 `bug`、第 12 课和第 16 课的 `box` 拼对后，页面上方出现可跳过的立体形象：弹出、转一圈并轻轻跳起，约 2.6 秒后停住。拼字板保持原正确反馈，不自动填字。点卡片、点「跳过」、按 Escape，或直接点「下一个单词」，都会离开这段动画；它不写入存档，不改变点亮、燃料或解锁。刷新已经拼对的题目不会重播。家长选择静态、系统要求减少动态效果，或图形不可用时，盒子沿用原有单词图，母鸡和小虫显示同风格静止图。

保存当前题目、已通过题目和未提交的字母排列；刷新后可续玩。第 1 课的看词状态直接由现有拼对记录派生，不新增存档字段。已点亮后重玩会重置本次题目与排列，但保留历史完成状态。

「一起合音」按用户操作依次播放当前字素的已有音频，再播放整词，并高亮对应字素；也可单独点读。当前素材是逐音与整词示范，不能据此声称已完成连续合音录音的人工教学验收。切换页面、题目、静音或播放其他音频时取消旧序列。

候选方块进入每题时重新排列，选取过程中位置保持稳定；刷新可重新排列，但已选草稿及各字素使用次数保持有效。`src/data/learning.ts` 显式描述前 16 课的字素—音素映射，`x`、`qu` 各显示两个音的标记，仍各占一个字素方块。第 1 课新增页内看词朗读，轻复习仍保留跨课看词观察；本课拼字完成条件不变。

连续点选通过函数式更新追加到最新草稿，并校验候选方块数量；异步保存不能覆盖前一次选择。字母完成、下一题、场景对话与首课对话确认检查发起操作时的课次和步骤，避免重复点击推进到下一轮。

### 6.4 P04 — 对话水晶星：开口说（已实现）

**开放条件**：本课沙丘全部题目已拼对。

**第一课：宇宙商店情景对话**

入口仍是第一课「对话水晶星」。商品选择卡显示单词、音标和中文释义，句子不标注音标。单屏展示机器人店主、柜台与商品、可点读字幕和底部家长操作，没有独立任务侧栏。

1. 问候：`Hello! Welcome to my shop!` → `Hello!`。
2. 购买：`What do you want?` → `I want an apple, please.` 或 `I want a gem, please.`。家长确认本轮尝试后，才可选择苹果或宝石。
3. 感谢：店主按选择递交物品，孩子练习 `Thank you!`。
4. 告别：`You're welcome! Have a great trip!` → `Bye!`。

支持「跟着说 / 关键词 / 自己说」，提示等级可随时切换。每轮可点「我来说」录音，再点「说好了」并回放或重录，最长 30 秒。录音仅在本轮页面内临时使用，不上传或写入存档；换轮、确认或离开时清除并释放麦克风。无法录音时仍可由家长确认或协助推进。系统不识别语音或自动评分。音频均由点按触发，字幕在静音或播放失败时仍可用。

完成四轮后，在当前页面回顾目标句子和本次补给。每种物品只收集一份，重玩或刷新不累计重复数量。点击「完成对话，点亮星球」才提交本课口语完成并开放下一课；旧版首课已完成记录保持有效。可重玩另一分支，历史课程完成不撤销。

**第 2、3、5–7、9–16 课：单句问答**

使用小猪、地图、小猫、母鸡、小虫和矿场词汇图片，练习 `What is it?`、`What do you see?`、`What do you like?` 和大小描述。可在本轮录音、回放和重录，最长 30 秒；录音仅在页面内临时使用，离开页面清除，不上传或写入存档。家长确认孩子尝试开口后点亮水晶星。第 16 课目前是单句购物表达练习，完整矿场购物游戏尚未实现。

**第 4、8 课：场景对话**

复用森林和沙丘的飞船场景以及已归位物体。第 4 课练习一轮 `What do you see? → I see a map.`；第 8 课练习三轮 `What do you see?`、`Where is the map?`、`Are we ready?`。每轮可点读机器人问题和示范回答，并录音、回放或重录，最长 30 秒；目标物体高亮；点击场景物体的图片或双语标签均可播放对应单词。录音仅在当前轮临时使用，换轮或离开页面时清除，不上传或写入存档。家长逐轮确认后点亮水晶星。

以上均只记录家长确认，不代表发音准确或已经掌握。

所有已实现口语页在请求麦克风及录音期间暂停示范，禁用问题、示范、场景点读与家长确认；仍可结束录音或离开页面。结束、拒权、失败和离开都释放播放限制及麦克风，回放与重录只在本轮有效。底层播放入口同样检查录音锁，防止其他入口在录音中发声。声音示范仍由用户主动触发，不进行识别或评分。

### 6.8 轻复习与家长陪学（已实现）

轻复习每组最多 3 项，包含看字母说音、看词拼读，满足先备条件时加入两词短语。仅从已进入课程中、所需音形规则全部已教的内容抽取，不使用 `oral_only` 图片词。优先再次练习最近需要帮助的项目，其余参考较早的复习记录与教学顺序；没有按日期自动开放、连续签到或强制时长。

另有显式标记为 `decodable` 的新组合试读：第 2 课已教 p/a/n 后可读 `pan`，第 3 课已教 m/a/t 后可读 `mat`。它们复用已有整词音频，按明确的规则依赖进入短练习，不因曾作为图片词出现就自动认定可解码。每组在有合适素材时穿插一个新组合，供家长观察规则运用。

短语为第 6 课起的 `red hen`、第 7 课起的 `big bug`、第 12 课起的 `big box`，逐词复用已有音频并明确标为「逐词示范」。这些是短语练习，不等同于已实现句子与故事课程。家长记录这些短语，或记录单词 `hen` / `bug` / `box` 的当次完成后，显示与拼读相同的立体形象；自己完成、提示后完成和一起完成都会显示，协助不取消这段鼓励，也不改变观察、点亮或燃料。

先展示字母、英文词或短语，孩子可尝试独立读出；点「听示范」后显示释义。家长选择「自己完成 / 提示后完成 / 一起完成」记录本次观察。使用示范后不能记录为自己完成。记录、当前题目、提示使用和本组结果可刷新恢复，与正式点亮、解锁、燃料分开；同一题的重复确认不重复记观察。历史最多保存 120 条，不保存声音。

「家长」面板增加本课目标、声音、拼读词、口语表达与领读方法的陪学卡，并显示最近 3 次复习观察。所有观察只反映当次表现，不作为已经掌握或发音准确的判定。家长预览中的复习同样仅在内存沙盒中生效。

家长可导出含学习、探索、复习与音量的 JSON 存档。导入检查格式与版本、1 MB 上限、课程先备条件、事件重复、燃料金额、探索位置和复习数据，展示完成课数、当前课次、燃料及观察条数后，由家长确认完整替换；不合并余额。导入通过统一保存入口，保存失败不报成功。预览期间禁止导入，导出始终使用正式存档。面板另可导出当前课程引用音频的 CSV 校对清单，初始全部标记待人工校对，不伪造审核记录。

## 7. 首个课程内容（Mission 01）

配置保留课程标识 `mission-001` 和名称「失落的能源方块」。当前先跑通三站学习，飞船迫降与能源修复的完整剧情尚未呈现。

### 7.1 字母音与三个例词

| 字母 | 音素 | 三个听说拓展词 | 图片内容 |
|---|---|---|---|
| s | /s/ | sun / snake / sock | 太阳 / 蛇 / 袜子 |
| a | /æ/ | apple / ant / alligator | 苹果 / 蚂蚁 / 短吻鳄 |
| t | /t/ | top / tiger / turtle | 陀螺 / 老虎 / 海龟 |

短 /æ/ 的例词采用美式英语。每个例词都有独立图片和整词音频；每个字母有独立音素音频。例词用于听说和建立声音联系，不作为独立拼读考题。

### 7.2 拼读与口语

- 拼读顺序：先由 /æ/、/t/ 合成 `at`，再由 /s/、/æ/、/t/ 合成 `sat`。
- 这两个词的字母均已在森林教授。`at`、`sat` 的含义不作为本轮独立考核重点。
- 口语使用宇宙商店四轮对话，练习问候、请求物品、感谢与告别。`gem` 及完整句型属于听说内容，不作为已学拼读规则考题。
- 只学 s / a / t 不足以独立解码 `cat`、`sun` 或大多数拓展词。第 2–16 课按累计教授的音形规则扩充拼读题，不能把听说例词直接当成可解码题。

### 7.3 节奏安排

周末约一小时是亲子共学场景的参考，不是当前三站原型的固定课时，也不是必须连续使用屏幕的时长。当前没有倒计时或强制学习时长。

家长可在字母学习、拼读与口语之间安排离屏休息、重复示范和额外交流。优先观察孩子的参与状态，可以分几次完成。

## 9. 当前技术架构与开发方式

### 9.1 已采用的技术

- **样式**：原生 CSS、CSS 自定义属性和媒体查询，当前没有引入 Tailwind CSS。
- **图像与图标**：项目内原创 SVG；航行控制台、宇宙概览，以及 hen / bug / box 拼对后的短时形象使用 Three.js 绘制 3D 场景并保留 SVG 回退，界面图标使用 `lucide-react`。
- **交互**：标准按钮点按，支持键盘焦点；第 4、8 课词语归位额外支持 Pointer Events 拖放，但始终保留点按替代操作。
- **声音**：本地 MP3，通过 `HTMLAudioElement` 按需播放。切换页面、步骤或音量时停止当前音频；新播放替换旧播放，并处理失败与静音提示。
- **状态**：React 状态 + `localStorage`，包含旧版迁移和重复完成幂等处理。
- **测试**：Vitest 验证状态逻辑；浏览器检查验证交互与响应式布局。
- **交付**：可运行的本地原型和 Vite 静态构建。已提供 Web App Manifest、iOS 主屏幕图标和独立显示配置；HTTPS 托管、离线缓存与云同步尚未实现。

### 9.3 音频开发与验收边界

`public/audio/space-ambience.mp3` 为原创合成的 16 秒无歌词背景音乐，四组和声缓慢交叉淡化，首尾作平滑处理；不使用外部样本，不作为教学发音素材。双声道、22,050 Hz、80 kbps，约 161 KB。资源完整解码通过，实际听感与 iPad 播放仍待人工验收。

第 9–16 课新增整词和口语句子试听音频，由 Samantha 合成；f、l、w、j、v、z、x、y 复用用户提供的字母音，qu 使用显式 /k/ + /w/ 生成的试听音。全部均待人工试听与教学验收，尤其要确认 x 为 /ks/、qu 为 /kw/。

当前共有 115 段原始本地 MP3，并额外保存 26 段用户提供的字母自然拼读读音文件。用户提供的文件集中保存在 `public/audio/letters/`，文件名为 `letter-a.mp3` 到 `letter-z.mp3`；课程通过 `/audio/letters/letter-字母.mp3` 引用，字母森林、复习声音扫描及拼读字母点读共用已开放的字母音。场景复习新增 `mat`、`rug` 两个整词及第 8 课后两轮对话的 4 段句子音频；重复使用的单词和问题复用原文件。原 `public/audio/phoneme-*.mp3` 合成音频保留用于对比或回退。全部素材仍待人工校对。

- 旧音素文件用 eSpeak-NG 的显式音素输入生成，脚本校验 IPA 事件是否为本课目标音，包括前 8 个音及新增 /ɑ/、/k/、/ɛ/、/h/、/r/、/b/、/ɡ/、/ʌ/。c 与 k 分别保留素材文件，但都教授 /k/；短 o 原型需重点人工校对。
- 另有 47 个用户提供的多字母发音文件保存在 `public/audio/graphemes/`，保留原始文件名和内容，作为后续课程备选素材；当前课程未引用。文件清单见 [多字母发音资源](MULTILETTER_AUDIO.md)，接入前需核对实际读音、教学先备规则和字素与音素映射。
- 整词与句子使用 macOS Samantha 合成；全量生成脚本需要 macOS 的 `say` 和 FFmpeg，运行网站本身不需要这些工具。
- 音频路径配置在 `src/data/lesson.ts`，替换素材不需要修改页面。
- 音素事件校验、文件能加载和能播放都不能替代人工试听。当前所有音频仍按待人工校对的原型试听素材管理，「家长」面板明确说明这一状态。
- 正式教学素材需人工确认音素与单词发音，特别是短 /æ/、/ɪ/ 及辅音不附加元音，以及整词合成。

### 9.4 iPad 兼容性重点

- 横屏优先，按 CSS 视口响应式布局并考虑安全区域；不依赖鼠标悬停。
- 所有学习步骤可通过点按完成，主要目标至少 48 × 48 CSS px。
- 音频由用户操作触发，支持重复播放和静音；iPad 实际音量也可用设备音量键调整。
- 浏览器支持时可由顶部按钮直接全屏；iPad Safari 顶部栏无法直接隐藏时，使用主屏幕独立窗口。该模式当前仍依赖可访问的开发服务或线上站点，不支持离线运行。
- 页面、当前学习步骤和拼字草稿可从本机记录恢复。
- 已完成桌面浏览器的 iPad 尺寸检查，仍须在真实 iPad Safari 上验证触屏、播放、布局和性能。

### 11.4 设计目标的后续观察

以下是人工验收时的观察问题，不增加埋点、自动评分、计时压力或课程开放条件。现有构建与浏览器检查不能据此证明学习效果。

| 设计目标 | 亲子或真机观察方式 |
|---|---|
| 首页清楚呈现下一步 | 孩子能否找到当前站，是否需要家长解释三站与长期课程的区别 |
| 递进提示支持自主重试 | 拼错后能否主动使用合音、调整排列并愿意继续，提示是否过早代替尝试 |
| 宇宙氛围可见但不抢任务 | 地图上能否感知星云，进入课堂后是否仍频繁追看背景，静态选择是否容易找到 |
| 声音入口符合预期 | 能否区分声音开关、音乐播放和自动暂停，是否理解刷新后音乐不会自行启动 |
| 音乐与录音舒适可用 | 真机上示范是否清楚、音乐音量是否合适、录音是否收进设备声音、拒权后能否继续 |
| 进度与备份可信 | 家长能否理解预览与正式进度、导入完整替换，以及没有自动跨设备同步 |

### 13.1 本轮迭代的决定依据

本表记录 2026-11-04 至 2026-11-05 几轮优化的理由。用户反馈、项目约束和已验证的实现问题是决定依据；关于理解难度、专注和学习意愿的收益仍是设计目标，需按 [11.4](#114-设计目标的后续观察) 观察，不写成已经证实的儿童学习效果。

| 问题或依据 | 当前决定 | 理由与保留的边界 |
|---|---|---|
| 眼前任务与包含未实现内容的 48 课总量混在一起 | 首页突出本课三站、当前入口及 N / 3；长期路径留在总览 | 以当前可操作任务组织信息，不把规划总量当作已开放内容 |
| 星图容易挤掉当前能做的事 | 首屏控制台先呈现位置、费用与动作；完整星域下移 | 当前任务与远期好奇心都有位置，只有地球和补给站可航行 |
| 重排方块不等于独立拼读 | 每题重排候选字素，主动点合音，逐音与整词分开呈现 | 减少照抄固定排列，保留可控示范；不把现有逐音素材称为已验收的连续合音录音 |
| 重排和跟读之间仍缺少看词迁移 | 仅第 1 课在拼对后进入大字看词，隐藏音标，保留字素、合音和整词帮助 | 给孩子先自己读的机会，需要时仍可听；不增加语音评分或完成门槛，其他课暂不扩大试验 |
| 48 课平铺会稀释当前任务 | 总览默认只展开当前单元，保留六单元入口，并可一键展开全部 48 课 | 折叠的是视觉噪声，不是课程入口；原选课、解锁和准备中状态完全不变 |
| 完成弹窗同时提供多个去向，奖励文案还可能误读完成状态 | 只留一个主要下一步，飞船入口回收至地图；按校验前状态区分首次与重玩，刷新后不确定时不猜报 | 让孩子先继续学习，让燃料反馈对应真实账本；不改变奖励金额、解锁或存档版本 |
| 重复相同错误提示没有提供新帮助 | 第二次未通过后静态突出合音，静音时请家长领读 | 增加可选帮助，保留重试，不自动填答案、不扣分、不记录负面等级 |
| 复习需要观察规则运用 | 每组最多三项，加入满足已教规则的新组合与短语 | 显式核对先备规则，家长观察不等于掌握，不改变解锁或燃料 |
| 故事标题需要在任务中有可感知结果 | 第 3 课用同一张地图串起线索、拼出 map、介绍与驾驶舱安装 | 从既有学习记录派生故事，不另存物品数量或重复发奖励 |
| 领读和存储说明容易挤占儿童区 | 家长面板集中陪学卡、观察、音量、备份与音频校对 | 家长能找到辅助信息，儿童区继续以图片和主要操作为中心 |
| 静音图标在无播放时像没有反应，用户期待音乐 | 喇叭打开可见面板，提供播放、暂停、状态和失败重试 | 操作结果可感知；音乐可选，打开面板不等于自动出声 |
| 第一轮星云过弱，增强后出现渐变矩形边界 | 云层移入视口并增亮，以显式椭圆渐隐消除裁切，课堂减弱 | 同时处理可见性与画面完整性，保留静态选择和系统减少动态效果支持 |
| 装饰与循环音乐可能干扰声音任务 | 视觉按页面暂停，音乐独立管理并低优先级播放，录音请求即互斥 | 教学优先；手动暂停不被自动恢复；播放成功与主观听感验收分开 |
| 快速操作和页面切换容易造成状态不同步 | 函数式草稿更新、提交防重、任务上下文校验、标题聚焦和实际停止旧音频 | 避免丢字、旧题结果回写与焦点丢失；录音和音乐各自清理资源 |
| 本机存储需要保护旧进度 | 保留原键与 v4，统一保存、预览隔离，备份校验后完整替换 | 保护完成记录与固定账本；主音量未提交时停止本次音乐，不伪报保存或云同步 |

完整行为与验证由本 PRD 维护；教学理由见[课程设计](Toms_Phonics_Universe_Curriculum_V1.md)和[情景对话设计](Toms_Phonics_Universe_Interactive_Dialogue_Design_V1.md)，航行取舍见[星际航行设计](Toms_Phonics_Universe_Space_Exploration_Design_V1.md)和[开发方案](SPACE_EXPLORATION_DEVELOPMENT_PLAN.md)。各文档维护自身职责内的依据，避免复制多份容易漂移的状态规则。
