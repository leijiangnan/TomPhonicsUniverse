## 本地运行

需要 Node.js 22.12+（本次使用 Node.js 26）与 npm。

```sh
npm ci
npm run dev
```

打开终端显示的地址。在同一局域网的 iPad 上，访问终端显示的 Network 地址；确保电脑防火墙允许访问该端口。

### iPad 全屏

- 页面右上角提供全屏按钮。浏览器支持 Fullscreen API 时，可直接进入或退出全屏。
- iPad Safari 若不允许网页隐藏顶部栏，点击全屏按钮会显示安装步骤：在 Safari 点击「分享」→「添加到主屏幕」，再从主屏幕打开「Tom 自然拼读」。
- 主屏幕模式使用独立窗口并隐藏 Safari 顶部栏。当前只配置独立显示，不提供离线缓存；电脑上的开发服务仍需保持运行。

```sh
npm test
npm run build
npm run preview
```

## 当前可体验内容

- 首页突出本课任务与当前站；航行控制台位于完整星图上方，起飞、学习与补给站入口在首屏。课堂保留大字母和三张点读图片卡。
- 星空使用本地 CSS 星光与边缘星云。地图和航行可轻微流动，学习区静止；所有弹窗及后台暂停持续动效。家长面板可选「轻动效 / 静态」，随原存档保存，系统减少动态效果优先，预览调整不写正式存档。
- 星空现为三层可见的蓝青、紫色云团与下方云带，课堂减弱，手机也保留可见层次。右上角喇叭打开「声音与音乐」，可主动播放/暂停轻音乐，并清楚显示静音与播放状态；默认不播放，刷新后关闭。
- 轻音乐只在地图、课程总览和航行时播放，音量为主音量的 20%；点读与录音优先，上课或后台暂停，手动暂停后不自动恢复。音量仍在「家长」中调整，不新增存档字段或跨设备同步。
- 常规拼读支持「一起合音」，依次点亮并播放各字素音，再播放整词。候选方块每题重新排列，已选草稿可恢复；逐音示范不等同于已人工审核的连续合音录音。
- 常规拼字本题两次未通过后，突出「一起合音」供主动选择；静音时提示家长领读，不自动揭答案、不扣分。进入新页面或任务后定位任务标题，弹窗保留焦点恢复。
- 学过声音后可进入轻复习，每组最多 3 项，支持看字母说音、看词拼读，以及满足规则后的 red hen / big bug / big box 短语。家长记录本次尝试，刷新续练；不改变课程点亮、解锁或燃料。
- 第 3 课以同一张探险地图串起三阶段；拼出 map 后找回地图，口语完成后装入驾驶舱。家长面板显示本课陪学卡与最近复习观察。
- 家长面板可导出完整 JSON 存档、选择文件查看摘要并确认替换。导入校验版本、先备条件、燃料账本、探索位置与复习数据；预览期间禁止导入，导出使用正式存档。录音不在备份中。
- 家长可导出课程音频 CSV 校对清单，填写审核人与问题记录。清单初始均为待人工校对，功能交付不代表发音审核完成。

- 「驾驶飞船」进入地球—虚构补给空间站航线。已实现课程每课最多 90 燃料，旧有效学习进度自动补发；首次抵达花费 50，往返免费。
- 航行控制台使用宽幅 Three.js 场景展示地球、虚构补给站、飞船和星空；全宇宙概览使用共享 3D 画布展示各星域天体与设施，并提供行星自转等示意动效。成功保存航行后播放飞船与镜头动画；静态偏好直接显示目的地，3D 加载失败时显示 SVG 示意图。
- 全宇宙概览收录 63 个地点。点击节点可查看距离、大小、简介与科学图片；仅地球和虚构补给站支持实际航行，其余仍标注筹备中。
- 空间站有三轮点读补给交流，家长确认后获得「补给先锋」收藏卡，支持中途刷新续学。补给方块和收藏卡不增加燃料。

- 三颗星球一行排列：「字母森林星 → 拼读沙丘星 → 对话水晶星」。完成后亮起、打勾并解锁下一站，首页显示点亮数量。
- 课程总览展示 6 单元、48 课，首页与课堂显示课次。「字母启航」和「单词矿场」第 1–16 课已实现，学完一课才能解锁下一课，第 17–48 课准备中。
- 字母森林：第 1–3 课学习 s/a/t、p/i/n、m/d；第 5–7 课学习 o/c/k、e/h/r、b/g/u；每音三个可点读图片词。第 4、8 课改为飞船场景声音扫描，分别复习 8 个和 17 个音。
- 单词矿场第 9–12 课学习 f/l、w/j、v/z、x/y/qu；第 13–16 课复习短元音、相邻辅音与已学规则。x 表示 /ks/，qu 表示 /kw/，qu 在拼词中占一个字素方块。第 16 课是配图购物句练习，完整购物游戏尚未实现。
- 拼读沙丘：常规课使用听音点字母；第 4、8 课将 4 个和 8 个可解码词拖到场景物体上，也支持「点单词→点物体」。双语备选词卡整卡可点读，归位后的场景物体也可点读；错误两次后给出高亮提示。
- 第一课对话水晶：宇宙商店四轮对话，可购买苹果或宝石；支持三档提示、家长协助、句子回顾和刷新续学。每种物品只收集一份，完成回顾后点亮星球。
- 第一课每轮可录音回放或重录，录音最长 30 秒，仅在本轮临时使用，不上传或写入存档；换轮、确认或离开时清除。需要浏览器麦克风授权和安全连接（HTTPS 或 localhost）；系统不自动判断发音。
- 第 2、3、5–7、9–16 课使用配图单句口语任务；第 4、8 课在同一飞船场景完成 1 轮和 3 轮情景对话。旧版已完成进度继续有效。
- 请求麦克风和录音期间，问题、示范、场景点读及家长确认暂时禁用；结束、拒权、失败或离开后恢复播放。录音仍只在当前轮次临时保留。
- 进度和音量保存到当前浏览器。沿用原存储键，内部 v4 兼容 v1/v2/v3。旧进度归到第 1 课，各课完成与草稿独立保存，复习不清除记录。
- 横屏优先，兼容竖屏及键盘导航。顶部提供全屏入口，家长说明与音频待校对提示集中在「家长」入口。
- 「家长」面板可开启当前会话的预览模式，直接查看已开发的第 1–16 课及课内三阶段；预览操作不写入正式进度，也不发放燃料。

### 声音与动效怎么用

1. 在星球地图、课程总览或航行页点右上角喇叭，打开「声音与音乐」，再点「播放背景音乐」；若已静音，按钮会显示「开启声音并播放音乐」。打开面板本身不会自动播放。
2. 「暂停背景音乐」会清除本轮播放意图；上课、点读、录音或后台引起的临时暂停，会在条件恢复后按原意图继续。刷新默认关闭音乐，音量在「家长」中调整。
3. 「家长 → 星空背景」可选轻动效或静态。视觉偏好独立保存，系统减少动态效果只影响视觉，不自动静音；节点详情暂停视觉时，音乐当前可以继续。

这样区分操作是为了让静音、播放与临时暂停都有明确结果；详细例外见 [PRD 声音优先级](docs/PRD.md#45-声音入口与播放优先级)。手动 JSON 备份保存学习、探索、轻复习、音量和视觉偏好，不保存音乐意图或录音，也不是云同步。

当前三颗星球是每课内部的三个阶段。尚未实现月球/火星航行、飞船升级、独立图鉴中心、第 17–48 课内容或自动跨设备同步。JSON 存档可手动转移，不等同于云同步。

## 音频状态

`public/audio/space-ambience.mp3` 是本站原创合成的 16 秒无歌词循环和声，约 161 KB，不使用外部样本，也不属于教学读音；完整解码已检查，实际听感和 iPad 播放待人工确认。

`public/audio/` 是随项目提供的本地 MP3，无需依赖浏览器 TTS 或第三方服务。当前文件是**待人工校对的试听素材**，不能据此认为已满足 PRD 的教学音频验收标准。「家长」面板标注此状态，家长可以静音并按照领读提示教学。

- 用户提供的 26 个字母音频集中存放在 `public/audio/letters/`，文件名为 `letter-a.mp3` 到 `letter-z.mp3`。课程通过 `/audio/letters/letter-字母.mp3` 引用；字母森林、复习声音扫描及拼读字母点读共用已开放的字母音。原 `public/audio/phoneme-*.mp3` 合成音频仍保留，便于对比或回退。
- 用户提供的 47 个多字母发音文件原样保存在 `public/audio/graphemes/`，作为后续课程备选素材，尚未接入当前课程。文件清单与使用说明见 [多字母发音资源](docs/MULTILETTER_AUDIO.md)。
- 音素生成脚本采用 eSpeak-NG 的显式音素输入。脚本会校验返回的 IPA 事件是否只包含目标音，避免输出字母名称或附加元音；这仍不能代替人工试听。
- 整词采用 macOS Samantha 合成。第 9 课使用 `sh scripts/generate-lesson-nine-audio.sh`，第 10–16 课使用 `sh scripts/generate-mining-audio.sh`；qu 音使用 `node scripts/generate-qu-audio.mjs` 显式生成 /k/ + /w/；新增音频均待人工试听。
- 运行 `sh scripts/generate-prototype-audio.sh` 可重新生成首版教学试听素材（不含背景音乐），需要 macOS 的 `say`、FFmpeg 与开发依赖。空间站新增 3 段音频可单独运行 `sh scripts/generate-station-audio.sh`。商店的 10 段句子音频单独运行 `sh scripts/generate-shop-audio.sh`，沿用 Samantha，仍待人工校对。单独生成音素可运行 `node scripts/generate-phonemes.mjs`。运行原型不需要生成工具。
- 正式给孩子使用前，应由有自然拼读经验的成人逐个试听、替换或确认发音，特别检查短 /æ/、/ɪ/、辅音不附加元音，以及拼读词的发音。
- 教学音频路径在 `src/data/lesson.ts` 及对应对话、复习配置中；背景音乐路径在 `src/lib/backgroundMusic.ts`。保持路径替换资源无需改页面，但替换后仍须核对内容与播放。

课程星球地图、机器人和单词插图使用项目内原创 SVG；航行控制台及宇宙概览使用 Three.js 绘制 3D 场景，并保留 SVG 回退。Nunito 字体已本地化，许可证见 `public/fonts/OFL-Nunito.txt`；页面运行不依赖第三方字体或音频请求。

## 验证范围

## 航行保存

`space` 与学习记录保存在同一份本地存档中。所有写入通过 Web Locks 串行化；局域网 HTTP 等不提供 Web Locks 的环境使用 IndexedDB 读写事务作为写入门控。两个页面存在旧快照时载入最新记录并提示重试，避免静默覆盖。写入失败时学习可以暂存于内存，航行和收藏确认不提交、不显示成功。浏览器禁用存储时无法可靠续学，也不能航行。
