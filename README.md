# Tom's Phonics Universe

面向一年级儿童的亲子自然拼读原型。开发需求基准见 [docs/PRD.md](docs/PRD.md)，项目开发约定见 [AGENTS.md](AGENTS.md)。

## 开发计划

[星际航行与成长系统开发方案](docs/SPACE_EXPLORATION_DEVELOPMENT_PLAN.md)：学习课程与四地点探索的实施范围、燃料规则、进度迁移、分阶段任务和验收清单。首轮地球—空间站已实现；月球、火星及后续任务仍按计划推进。

## 本地运行

需要 Node.js 22.12+（本次使用 Node.js 26）与 npm。

```sh
npm ci
npm run dev
```

打开终端显示的地址。在同一局域网的 iPad 上，访问终端显示的 Network 地址；确保电脑防火墙允许访问该端口。

```sh
npm test
npm run build
npm run preview
```

## 当前可体验内容

- 「驾驶飞船」进入地球—虚构补给空间站航线。已实现课程每课最多 90 燃料，旧有效学习进度自动补发；首次抵达花费 50，往返免费。
- 全宇宙概览收录 63 个地点。点击节点可查看距离、大小、简介与科学图片；仅地球和虚构补给站支持实际航行，其余仍标注筹备中。
- 空间站有三轮点读补给交流，家长确认后获得「补给先锋」收藏卡，支持中途刷新续学。补给方块和收藏卡不增加燃料。

- 三颗星球一行排列：「字母森林星 → 拼读沙丘星 → 对话水晶星」。完成后亮起、打勾并解锁下一站，首页显示点亮数量。
- 课程总览展示 6 单元、48 课，首页与课堂显示课次。「字母启航」第 1–8 课已实现，学完一课才能解锁下一课，第 9–48 课准备中。
- 字母森林：第 1–3 课学习 s/a/t、p/i/n、m/d；第 4 课复习前 8 个音；第 5–7 课学习 o/c/k、e/h/r、b/g/u；第 8 课复习全部 17 个音。每音三个可点读图片词。
- 拼读沙丘：8 课共 24 道累计可解码词练习，支持听音、点选字母、移除、重试、中文释义与继续。
- 第一课对话水晶：宇宙商店四轮对话，可购买苹果或宝石；支持三档提示、家长协助、句子回顾和刷新续学。每种物品只收集一份，完成回顾后点亮星球。
- 第 2–8 课使用配图单句口语任务。旧版第一课已完成进度继续有效。
- 进度和音量保存到当前浏览器。沿用原存储键，内部 v4 兼容 v1/v2/v3。旧进度归到第 1 课，各课完成与草稿独立保存，复习不清除记录。
- 横屏优先，兼容竖屏及键盘导航。家长说明与音频待校对提示集中在「家长」入口。
- 「家长」面板可开启当前会话的预览模式，直接查看已开发的第 1–8 课及课内三阶段；预览操作不写入正式进度，也不发放燃料。

当前三颗星球是每课内部的三个阶段。尚未实现月球/火星航行、飞船升级、独立图鉴中心、存档导入导出、第 9–48 课内容或跨设备同步。

## 音频状态

`public/audio/` 是随项目提供的本地 MP3，无需依赖浏览器 TTS 或第三方服务。当前文件是**待人工校对的合成试听素材**，不能据此认为已满足 PRD 的教学音频验收标准。「家长」面板标注此状态，家长可以静音并按照领读提示教学。

- 音素采用 eSpeak-NG 的显式音素输入 （共八个音；短 i 使用 `[['I]]`）。生成脚本会校验返回的 IPA 事件是否只包含目标音，避免输出字母名称或附加元音；这仍不能代替人工试听。
- 整词采用 macOS Samantha 合成。
- 运行 `sh scripts/generate-prototype-audio.sh` 可重新生成全部素材，需要 macOS 的 `say`、FFmpeg 与开发依赖。空间站新增 3 段音频可单独运行 `sh scripts/generate-station-audio.sh`。商店的 10 段句子音频单独运行 `sh scripts/generate-shop-audio.sh`，沿用 Samantha，仍待人工校对。单独生成音素可运行 `node scripts/generate-phonemes.mjs`。运行原型不需要生成工具。
- 正式给孩子使用前，应由有自然拼读经验的成人逐个试听、替换或确认发音，特别检查短 /æ/、/ɪ/、辅音不附加元音，以及拼读词的发音。
- 音频路径配置在 `src/data/lesson.ts`。替换文件即可，不需要修改页面。

所有星球、机器人、单词插图均为项目内原创 SVG。Nunito 字体已本地化，许可证见 `public/fonts/OFL-Nunito.txt`；页面运行不依赖第三方字体或音频请求。

## 星域科普与图片状态

62 个方案节点都有距离、大小或与太阳的比较及简介，资料来源在 `src/data/space/science.ts`。59 张科学图片已下载到 `public/space-images/`，运行时不需要联网加载第三方图片；原始下载地址与调研记录保存在 `artifacts/science-research/`。

图片按内容标为观测图像、巡天观测图、相关区域观测图、示意图或艺术家想象图。轨道位置和虚构设施不伪造真实照片，图片加载失败回退到原创示意图。主要来源为 NASA、ESA/Hubble、ESO 和 NASA SkyView；弹窗保留逐图来源、署名与许可入口。婚神星采用 VLT/SPHERE 观测图（CC BY-SA 4.0），木星图片含 Kevin M. Gill 的增强处理（CC BY 3.0），其余按来源页条款使用。当前完成了资料覆盖、图片完整性和浏览器检查，尚未完成逐条人工科普审核与素材许可终审，不能视为已审定的儿童科普教材。

## 验证范围

自动测试覆盖 48 课路径、课程规则依赖与资源、前 8 课逐课解锁、跨课保存、10 步以上复习进度恢复、旧版进度迁移、星球解锁条件、拼字校验、燃料奖励与重复学习。浏览器检查覆盖课程路径、新课学习流程、刷新恢复与横竖屏布局。

星域测试另外覆盖 62 个节点的资料与来源完整性、59 张本地图片的存在性及关键图像性质和署名。隔离浏览器会话已检查地球、虚构补给站、比邻星 b、沃尔夫 359 和人马座 A* 的详情，以及 1194 × 834、1024 × 768、390 × 844 的弹窗滚动和横向溢出；Escape 关闭与焦点恢复可用。科普数字、图像与节点对应关系仍需人工终审。

桌面浏览器的 iPad 视口检查不能替代 iPad Safari 真机验收；真机仍需检查触屏、音频播放及安全区域。清除缓存或更换浏览器会丢失本机学习记录。

音素生成器使用 [eSpeak-NG 的 Emscripten 封装](https://github.com/echogarden-project/espeak-ng-emscripten)（GPL-3.0），仅作为开发依赖，不随网站打包。

## 航行保存

`space` 与学习记录保存在同一份本地存档中。所有写入通过 Web Locks 串行化；局域网 HTTP 等不提供 Web Locks 的环境使用 IndexedDB 读写事务作为写入门控。两个页面存在旧快照时载入最新记录并提示重试，避免静默覆盖。写入失败时学习可以暂存于内存，航行和收藏确认不提交、不显示成功。浏览器禁用存储时无法可靠续学，也不能航行。
